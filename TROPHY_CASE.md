## How to check

"machine-verified" means: the object is in this repository, a checker written for the release passes on it (output in
`known-knowns/<family>/verify-it-yourself/RECEIPTS.md`), and before that it was re-checked by two or three separate reviewers,
each with their own code.

"Regenerate" (rather than only check) means rerunning the code that produced the object: every family has a
`how-we-built-it/` directory with that code, its pinned requirements, the exact commands and a smoke-run record
(`how-we-built-it/SMOKE.md`), and a `HOW_WE_FOUND_IT.md` with the story of the search. Any step that could not be
recovered is marked as such there.

Commands are run from the repository root. Rows 51–52 need `python3` with `numpy` and `onnxruntime` and download the
benchmark files (pinned commit, sha256-checked); row 53 needs `torch`, `torchvision` and `robustbench` and downloads
CIFAR-100 and the model weights. Compile the graph checker first:

```sh
cc -O3 -o known-knowns/biggest-graphs/verify-it-yourself/ddcheck known-knowns/biggest-graphs/verify-it-yourself/ddcheck.c -lpthread
```
