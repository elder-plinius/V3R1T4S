# Run it yourself

From this package folder, in a fresh shell (python3 3.8 or later; standard library only):

```sh
sh verify-it-yourself/run_checks.sh
```

The last line should be `ALL CHECKS PASS`. It takes about 15 seconds. Steps:

1. `reassemble.py` joins object/q5_cyl_14_cert.bin.part00 and the following parts, checks each part's and the whole file's sha256 against object/PARTS.txt
   (whole file sha256 d225ef1cf4f8f3c335620d5c7e37c5d96afa60cdc47b228acce51b66065a91e1). `check_object_files.py` checks the sha256 of the other object files.
2. `check_cert.py` reads the file (format in object/BOUND.md), checks n = 81433, checks every entry of v and y is positive, finds the smallest and
   largest exact ratio y_i / v_i with integer fractions, and computes the largest ratio to the power 1/14 in 80-digit decimal arithmetic. It checks, in exact
   integers, that the stated value 3.25040520587854968506 is an upper bound (its 14th power is at least the largest ratio) and is the upward rounding at 20 decimals.
   Expected: the bound 3.2504052058785496850598..., and a difference of about 1.939159726e-6 from the published 3.250407145038276.
3. `orbit_check.py` rebuilds the symmetry-orbit quotient independently for the three small certificates in object/format_examples/ and checks, in exact integers, that
   the file's y equals the quotient matrix applied to the file's v. This validates the reading of the format and the numbering of the orbits.
4. `small_check.py` computes the dominant eigenvalue of the transfer matrix for small widths directly (pure python without numpy; numpy is used if installed) and compares it with object/THETA_TABLE_q5.txt.
5. Negative controls: a corrupted y entry and a corrupted small certificate must be rejected.

The inequality. W_sq(5) <= theta(C_m)^(1/m) for even m is equation (6) of Lundow and Markstrom (2008), Section 4, not "Theorem 2.2" (the claim folder's label was wrong).

What step 1 to 5 do not do: they do not check, for the width-14 certificate itself, that the stored y equals the transfer matrix applied to v. That is the optional full check:
verify-it-yourself/full-check/FULL_CHECK.md (the panel reproduce skeptic's independent C program, about 25 minutes on 28 threads, exact integer arithmetic on the full 268435460-state matrix).
The panel ran it and found 0 mismatches in 81433 orbits (panel/reproduce.md).

How to rebuild the object. The search program is in how-we-built-it/ (potts_kink_cert.c); how-we-built-it/README.md gives the command and says plainly which
details the snapshot did not record (flags, iteration count, run time). The shipped file cannot be regenerated byte for byte; a fresh run gives another valid certificate whose bound agrees to many digits.
To split a certificate file into parts the way the object is stored: `split -b 900000 -d -a 2 q5_cyl_14_cert.bin q5_cyl_14_cert.bin.part`.
