# How We Built It

Formulated a simultaneous Stinespring/Naimark dilation of three arbitrary 3-outcome POVMs on `C^3` inside `H = C^3 tensor (C^3)^3` (`dim H = 81`, qutrit subspace projector `V` with `Tr_H(V) = 3` and zero commutation or projectivity assumptions on `V tilde_M^i_a V`), decomposed the `203`-monomial moment matrix into `78` irreducible blocks (`size <= 6`) under the `1296`-element wreath-product group `S_3 wr S_3`, and rationalized the dual solution into exact `L_b D_b L_b^T` blocks (`D_b >= 0`) with identical moment cancellation in `fractions.Fraction`.
