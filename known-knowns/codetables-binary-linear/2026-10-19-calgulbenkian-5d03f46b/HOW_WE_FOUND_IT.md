This account is the contributor's description as recorded in the claim folder, not something the panel checked.

The contributor's team used an AI search agent (Gemini, called Argon) on 2026-10-18 and 2026-10-19. Its goal was qubit stabilizer codes with distance 4 in cells of the codetables.de quantum code table where the table's lower bound was 3 and its upper bound was 4. The agent built one file holding six codes, [[37,26,4]], [[39,28,4]], [[43,32,4]], [[45,34,4]], [[47,36,4]] and [[49,38,4]], each with 11 independent commuting generators. Per the file's own method field, they are extensions of a [[64,53,4]] code with 11 parity checks, found by what the file calls a wedge-kernel zero-conflict extension. The file lists which 37 to 49 columns of the base code are kept and the extension columns.

The orchestrator's triage agent then checked the file with its own program (commutation, rank, no zero-syndrome Pauli of weight 1 to 3, a weight-4 element of the normalizer outside the stabilizer) and found no fault, and checked that the table's own propagation rules do not give the value. The three panel skeptics repeated this independently (see panel/).

What failed or was tried before is not recorded in the claim folder or in the snapshot available to us.
