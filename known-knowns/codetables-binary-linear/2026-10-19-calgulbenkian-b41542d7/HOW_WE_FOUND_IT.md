# How we found it

Found on 2026-10-18 by the contributor's team (an AI search agent, Gemini "Argon"). The method is a Delsarte linear program over the Krawtchouk polynomials for the chosen length and size: find non-negative rational multipliers so that the polynomial is non-positive at every integer weight from the excluded distance to n while its value at 0 stays below q^k. The program in `how-we-built-it/` found multipliers for ten cells in this family; this package holds one of them.
