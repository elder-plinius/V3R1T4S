# How we found it (contributor text, unverified)

The constructor lens of this run found that the lexicographic product O[K2] of an order-k instance O with Knuth's order-2 instance (men rank by O-rank then inner rank; women likewise, inner order reversed) is exactly the Irving-Leather doubling: applied to Knuth's order-4 instance it reproduces 268 at n = 8 and 195472 at n = 16. The OEIS A357271 even-order values are such compositions of older blocks. Applying the same doubling to the newer order-9 block of Ong et al. (2025), which has 365 stable matchings, gives this order-18 instance with 530528 stable matchings, counted by a memoised rotation-poset DP, a lattice walk that re-checks every matching, a reverse-search enumeration that re-checks every matching, and a Python lattice walk. The run's PREREG.md froze the strict-improvement rule and the agreement-of-counters rule before any output was scored.
