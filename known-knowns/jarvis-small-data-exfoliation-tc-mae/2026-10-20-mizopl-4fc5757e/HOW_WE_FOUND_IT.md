# How We Found It (`contributor text, unverified`)

*Note: contributor text, unverified.*

1. **Diagnosing the Small-Data Bootstrap CI Bottleneck**: On small-data solid-state benchmarks ($N < 1,000$), standard compositional and structural descriptors (`Magpie` + `CFID`) with GBDT (`matminer_xgboost`) or global Laplace kernels suffer from heavy-tailed outlier errors on crystals belonging to distinct mechanical cleavage regimes, inflating the 1,000-sample bootstrap 90% confidence interval half-width $h_{90\%}$.
2. **Griffith 3D-Covalent Fracture Regime (`dft_3d_exfoliation_energy`)**: In `how-we-built-it/featurize_physics_clss.py` (`sha256: 3675beadd412c1ef37ca162519c30364e4d3b25990cd53ebf3719f5f1382798a`) and `how-we-built-it/train_and_predict_jarvis_clss.py` (`sha256: 7c456ccf602ac5ac8efe9faa8276d1bd26cb41f6f4e108ad740d7d287eb4b806`), separating 3D covalently percolated crystals ($\alpha_{\text{perc, 3D}} \le 1.05$ covalent radii with zero soft ionic spacer atoms) from 2D van der Waals layered crystals and selecting the regime blending weight ($w_r = 0.80$ over `np.linspace(0.0, 1.0, 21)`) automatically by analytical leave-one-out (`LOO`) cross-validation on `train U val` ($n = 731$, analytical LOO MAE = `31.805270 meV/atom`, 5-fold CV OOF MAE = `32.672745 meV/atom` vs reproduced `matminer_xgboost` = `45.004627 meV/atom`, Wilcoxon $p = 1.62 \times 10^{-18}$, `p2`) yields the frozen model's official Test MAE of `28.195924 meV/atom` (`-31.04%` below `matminer_xgboost = 40.887 meV/atom`, $h_{90\%} = 11.132579\text{ meV/atom}$).
3. **Post-Hoc Ablation Note & Dated Provenance Disclosure**: Because the initial commit `4b8939d` (`2026-10-21`) committed the feature/kernel code and test predictions together (and `how-we-built-it/PREREG.md` was written retrospectively on `2026-11-03` during commit `ed4d4dd` and has been removed), there is no separate pre-run git commit dating the fixed kernel hyperparameters ($\tau = 0.45 \cdot \mathrm{median}(y_{\text{tv}})$, Laplace scales `3.0` and `(6.0, 2.0)`, ridges `0.025` and `0.030`, or the Griffith 8-feature definition) prior to `4b8939d`. As a post-hoc note, setting $w_r = 0$ (base multi-view Laplace KRR only, without the Griffith fracture regime branch) gives `train U val` analytical LOO MAE = `32.724774 meV/atom` and Test MAE = `30.402496 meV/atom` ($h_{90\%} = 13.220252\text{ meV/atom}$). For the same provenance reason, `p1` credit on `tinnet_N_ead` (`0.068908 eV` vs `0.0871 eV`) is dropped and reported only as an uncredited supplementary evaluation.
