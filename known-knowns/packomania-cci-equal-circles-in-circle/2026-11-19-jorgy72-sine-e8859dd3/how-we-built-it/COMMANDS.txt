Known blemish, not fatal: the run's mpmath checker prints r* and the table
value with mp.nstr(..., 31) — 31 significant digits, not 50 — so the run
folder's *_check50.log prints are 31-digit truncations of the true 50-digit
values. The print truncation is ~1e-33 absolute, 19 orders below the bar
and 24 orders below the margin; the three panelists computed the true
50-digit values independently from the exact coordinate strings and agree
to every printed digit. The package verifier (verify.py) parses decimals
exactly and prints the true values. All verdicts in this package use
recomputed values only.
