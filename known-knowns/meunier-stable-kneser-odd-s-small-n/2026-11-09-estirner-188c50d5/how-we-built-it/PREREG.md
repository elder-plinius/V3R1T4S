## Definitions (from arXiv 2607.12912, abstract)

- [n] = {1, ..., n}. S is s-stable if min{j - i, n + i - j} >= s for all i < j in S.
- KG(n,k)_{s-stab}: vertices are the s-stable k-subsets of [n]; two are adjacent iff disjoint.
- Here k = 3, s = 5, n in {17, 18, 19, 20, 21}; C = n - sk + s - 1 = n - 11 colours for the UNSAT side,
  C + 1 = n - 10 colours for the colouring side.
