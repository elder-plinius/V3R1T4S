# How it was found (contributor text, unverified)

Greedy addition of small atoms to Tomar's measure reached about 1.70365 and did not converge. The holes left were thin slivers beside the rows. Replacing one row by a line density did worse (about 1.6955, capped search), so discrete atoms were helping. A float search on one strip of unit height, for equal atoms on L staggered levels covering the strip with the least density, gave a tile table (how-we-built-it/brick.c, tile.c). Rows built from that tile by a formula, on a frame rounded to 3.3, 2.75, 4.0, beat Tomar's value with no search at L = 2 and L = 3 (1.703884260988, 1.706007457027). 180 s of float search over the 28 parameters at L = 3 gave this object. Floats were search only; the value is from the exact programs.
