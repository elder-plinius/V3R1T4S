# Prompt provenance

`RUN_PROMPT.txt` is an archived copy of the workspace's scheduled prompt for
`sorting-network-size-records`, with the workspace path replaced by
`<WORKDIR>`. It is included for historical context. The Condorcet search that
produced this certificate ran under a separate manual brief.

The [run preregistration](../how-we-built-it/PREREG-run.md) records the scope of
the Condorcet continuation that started at 00:15 UTC on November 4, 2026. The
[task preregistration](../how-we-built-it/PREREG-task.md) records the binary
prefix DAG search that produced the 186,310,276-order assignment. The
[verification preregistration](../how-we-built-it/PREREG-verification.md)
records the later check of the frozen assignment and the published comparison.

See [RUN_IT_YOURSELF.md](../RUN_IT_YOURSELF.md) for reproduction instructions.
