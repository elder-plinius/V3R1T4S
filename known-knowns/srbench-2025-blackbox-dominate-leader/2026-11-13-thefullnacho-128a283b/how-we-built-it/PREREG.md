Procedures fixed before scoring (dataset 522_pm10; both lenses select on TRAIN data only — no test R2 is used for any selection):
- Lens 1 (constructor, beam small-expression search) = per split: inner 80/20 split of train via sklearn train_test_split(test_size=0.2, random_state=0). Beam search over expression trees: leaves are the 7 features and the constant 1; unary ops sin, cos, square, sqrt(Abs(.)), log(1+Abs(.)), Abs(.); binary ops +, -, * only (no division). Search complexity = tree node count (leaf 1, unary child+1, binary left+right+1), cap 12. Beam width 800 per complexity level; candidates scored by inner-validation R2 of the affine fit y ~ a + b*E (OLS on inner-train, scored on inner-val); keep the top 800 by that score at each level; also track the best candidate overall (any level <= 12). New candidates at each level are unary ops applied to current beam members and binary ops between a beam member and a leaf (feature or constant 1). Final expression for the split = the best-overall candidate by inner-val R2, with a,b refit by OLS on the FULL train; serialized at full float precision. Non-finite candidate values are dropped (never scored). If the beam search fails on a split, fall back to the single best feature by inner-val R2 (affine fit) — deterministic, no test data.
- Lens 2 (smuggler, GAM shape compression) = per split: backfitting on train only, 8 rounds, no damping. Each feature's shape is a binned-mean smoother: 20 quantile bins of the train values of that feature, bin means of the partial residual, then 3 passes of [1,2,1]/4 smoothing over bin centres, evaluated by linear interpolation (np.interp) between bin centres, constant outside the range. After backfitting, each shape is compressed: evaluate the fitted shape on a 60-point grid (train quantiles of that feature, 0..100%); greedy stepwise fit of the grid shape values using the per-feature library {1, x, x^2, Abs(x), sqrt(Abs(x)), log(1+Abs(x)), Max(0,x-q25), Max(0,x-q75), Max(0,q25-x), Max(0,q75-x)} plus, for the two cyclic features hour_of_day (P=24) and day (P=365.25) only, {sin(2*pi*x/P), cos(2*pi*x/P)}; at most 3 terms per shape (constant counts as one of the 3 only if selected as a term — the shape's own intercept is absorbed in the joint refit, so the constant 1 is NOT in the compression library); stop at grid-MSE gain < 0.001. Assemble y = c + sum over features of compressed shapes; refit ALL coefficients jointly by OLS on full train; expression serialized at full float precision. If a shape's compression selects 0 terms (cannot happen: greedy always takes the best first term) or a shape is constant, that feature contributes nothing.
