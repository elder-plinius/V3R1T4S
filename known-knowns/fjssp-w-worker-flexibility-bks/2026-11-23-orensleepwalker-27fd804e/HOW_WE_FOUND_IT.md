# How we found it (contributor text, unverified)
A teammate agent ran a three-day campaign over the open FJSSP-W rows that no pull request had claimed yet. The main engine is a critical-path tabu search on the machine-and-worker disjunctive graph, compiled with Numba (how-we-built-it/code/numba_ts*.py, four versions: iterated multi-start, cleaner move evaluation for crowded machines and workers, and an exact joint insertion that finally cracked the six 100-job Behnke instances). Rows where tabu search stalled went to CP-SAT with the makespan capped one below the value to beat, in escalating 10, 20 and 40 minute rounds, and the last two holdouts to longer CP-SAT runs with Carlier-style cuts. Rows by engine: {'tabu search numba_ts_v3': 18, 'tabu search numba_ts_v2': 57, 'CP-SAT capped below the bar': 51, 'tabu search numba_ts_v4': 8, 'CP-SAT LNS with tabu polish': 1, 'CP-SAT with Carlier-style cuts': 1}. Before freezing the claim we re-timed 6,355 public competition and solver schedules against our rows and read every reported value; three rows fell and were dropped.
