## Escape hatches (declared now)

- A published row whose forecast file cannot be fetched (404 under the Monday file name and not found under another
  date by one directory-listing request) is reported as missing; that model is then compared on its covered rows and
  flagged. If more than 5% of a model's rows are missing, that model is reported as "not reproduced" (not as a
  match).
- If the run ends before all models are recomputed, the report says which were done and claims nothing for the rest.
- If a >1% discrepancy appears, its cause is investigated row by row; a cause is stated only if it is shown by
  output (for example: the row reproduces exactly under the declared alternative truth vintage, or under a stated
  rule). Otherwise it is reported as "unexplained", and the p3 claim then covers only what is explained.

## Scorer validation (before scoring hub files)

< 1e-9), on a known positive (point forecast => WIS = |y - m|) and a known negative (a 1/(K+1) normalisation differs).
