# How we found it (contributor text, unverified)

The target was the first term of A002851 past the OEIS b-file (42 vertices). Method A (the Cheng-Xu histogram recurrence over cycle types, in Python and in a C port with residues modulo primes and CRT) gave A002851(21) on 2026-11-14 but was one method. A second method B (direct coefficient extraction per cycle) only reached cycle types with at most 11 cycles, so for several nights 26005 of the 53174 cycle types at N=42 had no second value. Method D handles fixed points and 2-cycles with a closed configuration-model formula in power sums, so its cost depends only on the cycles of length >= 3; with a symmetric count-vector DP for many long cycles it covered every N=42 type in about 1.1 hours on 2 cores, agreeing with method A on all of them. Gates before the run: the identity type against A002829 to N=42, all types to N=8 against brute-force enumeration, all types to N=14 against method A, and the b-files to 40 vertices. Values are computed modulo 2^521-1 (each is at most A002829(42), 72 digits); 359 N=42 types were recomputed modulo 2^607-1 with the same results.
