# How we found it (contributor text, unverified)

The brief: extend the OEIS tables of connected regular graphs by one exact term, with two independent methods. Method A, a C port of the Cheng-Xu histogram recurrence with CRT over word-size primes, gave U_6(N) to N=30 quickly. Method D, a separate per-cycle-type count (a vertex DP for fixed points and 2-cycles, a symmetric count-vector DP for longer cycles, modulo 2^521-1), was the slow part. Its first versions ran out of memory on types with many fixed points. A C port of the short-part DP and a reachability prune made d=6, N=25 fit in one night on 2 cores. Both methods agree on U_6(25). The same method-D code reproduces every published term of A165627 and A006822, and the inverse Euler transform gives the new connected term. Earlier, the same pipeline gave A002851(21) (cubic). At degree 4 it matches Cheng and Xu's published tables for orders 29..46.
