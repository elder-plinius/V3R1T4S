# How we found it (contributor text, unverified)

This is a refile of the contributor's earlier pull request #106 for the same packing. The packing for N = 170 in the unit 4-ball was found by an AI search agent (Gemini, working for the contributor) in two stages. First it built a start from two posted packings: it took the inner 20 spheres of a 166-sphere packing, turned them inside the frozen outer shell of a 169-sphere packing, and let all 170 spheres relax. That reached a radius of about 0.215637. Then a second program polished the result by a smooth approximation to the minimum-distance problem, raising the weight step by step and adding a little random jitter, which gave 0.2156450594684, above the posted 0.215589695168. The run commands are not recorded. The radius in the object's header line differs from the exactly computed value in the 17th digit; the checker reads the coordinates, not the header.
