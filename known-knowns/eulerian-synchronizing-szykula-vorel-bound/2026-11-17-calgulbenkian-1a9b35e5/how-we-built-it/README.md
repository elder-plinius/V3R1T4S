# How We Built It

Szykula & Vorel (DLT 2016, `arXiv:1604.02879`) proved their `floor((n^2 - 3)/2)` lower-bound series using 4-letter automata whose non-permutational letters are unitary (`p -> q` fixing `Q \ {p}`), where Lemma 3 enforces greedy backward subset extension on `Q \ {p}`, and verified Conjecture 19 exhaustively up to `|Sigma| <= 4` for `n <= 7` and `|Sigma| = 8` for `n <= 5`. Targeting the first unexplored frontier `(n = 7, |Sigma| = 5)`, we parameterized 5-letter Eulerian automata using two complementary non-unitary defect-1 letters (`4 -> 0` and `0 -> 4` composed with `(1 2)` on the complement) plus three permutations, preserving exact incoming edge count `5` at every state while breaking unitary backward greediness. Simulated annealing over exact `2^7` bitmask subset-BFS landscapes discovered `object/eulerian_n7_k5_rt24.json` with exact reset threshold `24 > 23 = floor((7^2 - 3)/2)`, verified independently by Python stdlib set-BFS and C99 bitmask-BFS referees.
