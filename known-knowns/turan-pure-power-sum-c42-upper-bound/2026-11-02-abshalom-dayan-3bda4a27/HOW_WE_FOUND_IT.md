# How we found it (contributor text, unverified)

An unattended run on track F started from the barrier at rho = 1/sqrt2. A hierarchy of integrated level bounds turned out to have value exactly 1/2, because a chattering control satisfies all its levels. Dynamic programming then showed that one fixed test functional, using Biro's formula (14), leaves a gap on all sign profiles at T = 1/2. Early margins were grid artifacts; a thin band and a smoothed value function kept a real margin at T = 501/1000. The proof turns this into finite inequalities on a table.
