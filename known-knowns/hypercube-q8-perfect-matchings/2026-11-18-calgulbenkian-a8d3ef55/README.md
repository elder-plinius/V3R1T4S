# Exact Residue `A005271(8) == 3 (mod 5)` for Perfect Matchings of the 8-Cube


## What

A005271(8) is congruent to 3 mod 5, obtained as the exact count 743141892135168 of perfect matchings of Q_8 fixed by the order-5 Sylow subgroup generated by the coordinate 5-cycle (0 1 2 3 4). Two implementations in the package agree, and a third checker I wrote agrees. The method reproduces A005271(7) mod 5 = 4. This is conditional on the residue not already appearing in the literature, which the novelty role must settle.

## Check It Yourself

From this package folder, run:

```sh
sh verify-it-yourself/run_checks.sh
```

Expected last output line: `PASS` (runs in ~`0.6` seconds on a laptop using only the Python 3 standard library, executing two independent zero-shared-code algorithms and reproducing `A005271(1..5)` in full-cube mode plus `A005271(5..7) mod 5` including Ostergard and Pettersson's `A005271(7) == 4 mod 5`).

## Not Claimed

- We do **not** claim the full integer count `A005271(8)` (the full moonshot target).
- We do **not** claim the full integer count of perfect matchings of the folded 8-cube `FQ_8` (`p1`).
- Only the single cell `A005271(8) mod 5 = 3` (with its exact `P_5`-fixed matching count `743141892135168`) is claimed in this package.
