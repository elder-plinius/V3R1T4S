# How the object was built

Python 3.14, python-flint 0.9.0 (Arb), numpy, scipy for the sanity scripts. The file map of `object/REDUCTION_FULL.md` (section 12) refers to `code/...`: the proof inputs are in `object/code/`, the numerical sanity scripts (K1, K3, V2, K4, edge-distance counterexample) with their outputs are in this folder, and the original REPRODUCE (Windows commands) is `REPRODUCE_original.md`. `PREREG.md` is the run's frozen rule (`null_test: not needed because ...`; no null_test.md is required).
