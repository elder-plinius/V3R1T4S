# Fast matrix multiplication: format 4x14x15 in rank 569, class Z

## What

The file object/4x14x15_m569_Z.json is an exact integer (class Z, largest absolute coefficient 2) bilinear scheme of rank 569 for the 4x14x15 format whose Brent equations hold over Z, and rank 569 is strictly below the Z rank 572 in the live Perminov README table, not below the overall best rank 557 and not matched by any Z-class scheme file in the two named repositories at the fetch time.

Path note: the sentence above is quoted word for word from `panel/gate.md`, and it names the panel's `claim/` folder. In this package the same scheme is `object/4x14x15_m569_Z.json`.

## Check it yourself

From this package folder, run:

```sh
sh verify-it-yourself/run_checks.sh
```

- **Requirements**: `python3` 3.8 or later, standard library only.
- **Rough laptop time**: under one minute.
- **Expected last line**: `ALL CHECKS PASS`

The run checks the object's sha256 against `INDEX.csv`, the Brent equations exactly over the integers (no floating point, no sampling), the coefficient class, and that a copy with one sign flipped is rejected.

## Not claimed

- Only the Z (integer) column is claimed. Nothing is claimed for any other coefficient class of this format.
- The scheme does not beat the best known rank for this format over the rationals (Q rank 557; fmm_sota 557). It is an improvement for the Z column only.
- This is a rank bound for one format and does not improve the asymptotic exponent of matrix multiplication.
- Not peer reviewed. It was checked by a three-skeptic panel (`panel/`) and by the standalone checker shipped here.
