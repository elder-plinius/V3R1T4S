# How We Built It

MinT's documentation (`desc_OBoundLP.html`) notes that its Martin-Stinson / Bierbrauer linear-programming lower bounds on ordered orthogonal arrays `OOA(M, s, S_b, T, k)` were precomputed only up to `s <= 8` at depth `T = 4`. By Lawrence (1996) and Mullen-Schmid (1996), any `(3, 11, 19)`-net in base `3` (`M = 3^11 = 177,147` points) embeds an `OOA(177147, 19, S_3, T = 4, k = 8)` by truncating each coordinate to its first `T = 4` ternary digits. Formulating the symmetrized `8,855`-shape multivariate Krawtchouk LP over `F = {(f_0..f_4) : sum f_i = 19}`, solving a sparse restricted-dual LP over `60` dual types (`1 <= |f| <= 11`), and clearing denominators to an exact 62-bit integer `L = 3,554,572,650,025,767,480` with exact non-negativity across all `8,854` non-diagonal shapes yielded `M >= 2403828588527406331 / 13544324988667 = 177,478.655491... > 177,147 = 3^11`.
