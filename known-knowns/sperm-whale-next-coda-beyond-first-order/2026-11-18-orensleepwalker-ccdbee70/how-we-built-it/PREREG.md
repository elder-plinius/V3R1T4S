# Whale campaign, v1

Scope: full local campaign authorized without a fixed wall-clock cutoff; serial CPU jobs with time caps and checkpoints. The target text in target.md governs thresholds. No submission.

## Folds and scores

Dialogue grouping is REC, sorted lexically and assigned modulo five. Order within REC by numeric TsTo with file order breaking ties. Predict capped click-count/duration quintile jointly. Duration cutpoints are training-only linear quantiles; use right insertion for ties. Alphabet is 50 physically defined tokens. Score from the third coda onward. R1 learns all adjacent training pairs and selects additive alpha from .01/.03/.1/.3/1 by pooled inner cross-validation, respecting REC groups and refitting boundaries. The scout R1 at 2.79478055297942 is the reproduction target under these conventions, tolerance 1e-12. No published numeric score for this exact baseline. Candidate n-gram and feature tables train on eligible scored positions.

Dominica uses exact protocol: normalize hyphens to slashes, sort dates lexically for folds, group by normalized Date and Unit, order by integer codaNUM2018, use both clans, score from third coda. Use a training-only vocabulary plus a reserve unknown token, so held-out unseen types have positive mass. Report raw unknown count. R1 uses the dialogue alpha-selection protocol. Report that the target leaves these smoothing and token-support choices implicit.

Turn-taking target is equality between adjacent labels in the same REC; no label identity across REC. Score from the third coda, where the previous same-or-switch value exists. Fit additive smoothed transitions of the binary stream with the same alpha grid. Numeric labels are used only through equality. No fields from the predicted coda enter any features. Include all valid rows. Report group and fold counts.

## First experiment

Model families: interpolated categorical backoff from unconditional to last token to the last two or three tokens, repetition-aware backoff using capped run lengths and prior distinct token, and hierarchical categorical timing backoff (the within-quintile location of the previous duration, previous inter-coda onset gap, previous duration slope, and speaker continuity when supplied). Turn-taking also evaluates previous call-token class and recent switch length. Use the same families and hyperparameter grid for the one-coda versions, with every input independently truncated before feature construction and retraining on the same training positions. Fix order and audit feature functions before any real scoring. For interpolation use pseudo-count strengths 1,4,16,64, and select within family using only pooled inner held-out log loss. Each route also reports the model selected across families inside training, with the same cross-validation and deterministic tie order. Record all family scores. No model chosen by outer folds can be treated as a preregistered winner. Any subsequent credible extension has a dated preregistration, discloses reused test folds, and requires new independent evidence to call a confirmatory result beyond this frozen suite.

## Uncertainty and controls

Use pooled per-position log loss in bits. Compute paired percentile intervals from 10,000 draws of whole REC or Date groups with replacement, weighting by number of positions in each draw, seed 20261118. Provide fold deltas, cluster influence and simultaneous context for claims across paths. For every threshold candidate, run 400 seeded null datasets (seeds 310000..310399), repeating feature generation, inner model selection, baseline and twin fitting, outer scoring and the same decision rule. First null shuffles coda payloads (click count, duration, label and other measured attributes jointly) within streams with fixed onset order, or uses within-stream swaps of CodaType for Dominica. It preserves stream composition and position count while breaking sequence alignment; report when real gain fails to beat the best null. Additional stronger stream-local first-order null for order-based models uses randomized Euler trails preserving adjacent token transition counts and starting token. Continuous-feature longer-history candidates also need a control that preserves the immediate feature/target relationship while breaking earlier history, with implementation fixed and recorded before testing that extension. Disclose the exact hypotheses these controls test and any residual stream effects. A full-win or partial claim additionally needs independent fit/score replication, future/target mutation checks and fresh review. No claim based on an unrun control.
