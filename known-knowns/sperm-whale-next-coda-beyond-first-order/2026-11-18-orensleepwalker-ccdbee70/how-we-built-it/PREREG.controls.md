# Implementation note for stronger first-order controls

Before executing any null seeds. PREREG.md already froze stream-local transition-preserving randomization. This note makes its implementation concrete for the two threshold candidates.

Dialogues: for each REC, encode capped click count and duration bin with the edges from R1 trained without that REC's outer fold. Generate an Euler trail from the original starting token, randomly ordering outgoing edges with Hierholzer's algorithm. Check that the directed transition multiset, starting token and length are identical. Randomly reassign raw count/duration/speaker payloads conditional on token within that REC, leaving the original sorted onset times intact. The preserved adjacency counts are exact under the REC's held-out tokenization. Training uses several independently fitted binning rules, so its adjacent counts are not necessarily held exactly. The shuffle is a diagnostic conditional surrogate, not a uniform draw of all possible trails or a formal exact randomization p-value.

Turn-taking: apply the same construction to adjacent same-or-switch bits within each REC. For nulls, reorder both click/duration payloads and time-associated covariates by using the ordinary payload shuffle, then encode the synthetic same-or-switch sequence using alternating labels 1 and 2 from the original first speaker. Individual speaker labels are abstracted away under this null. Preserve transition counts exactly. Report both ordinary payload shuffles and these separate, stronger first-order controls. Replicate the nested selection procedure on every control. For primary decisions, compare the observed selected model's gains with null maxima for baseline and twin separately. Also report the max over all named families as a sensitivity analysis to multiplicity. If any required check is incomplete or the real gain does not exceed the strongest relevant control, do not call the result confirmed.
