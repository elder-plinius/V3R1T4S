On real farms whose shortest stored route set is RADIAL while the branched MILP run stopped at its time limit with a longer result, we re-optimised windows of about 30 neighbouring turbines with everything else held fixed, many times over, with OR-Tools CP-SAT through optiwindnet's own branched model, keeping each change only if the network got shorter and still validated (the method behind PRs #967, #968, #977-#982, #1027-#1030). On 2026-11-09 we applied it to six leftover instances with that profile, one search each; two improved past our review threshold (this one and Sofia capacity 4). Here the best network the branched search found happens to have no branch points: it is a radial route set, only 2.87 m above the stored radial MILP bound.
