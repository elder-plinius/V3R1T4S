# How the object was produced (provenance, not a replay guarantee)
how-we-built-it/lns_branched.py: starting from a stored route set, repeatedly pick a random turbine, keep a window of its 22-34 nearest turbines free, pin every other turbine's outgoing link, and re-solve with optiwindnet's OR-Tools CP-SAT model (branched, segmented feeders, feeder cap = the shortest stored set's, 30 s per window, warm start from the incumbent, 1 worker, seed 7); accept only shorter route sets that pass validate_routeset and how-we-built-it/checks.py (border and obstacles). Frozen plan: how-we-built-it/PREREG.md and PREREG.v2.md. Solver timing makes replays differ; the frozen object is authoritative.
