On the large real farms whose shortest stored route set is RADIAL while the branched MILP run stopped at its time limit with a longer result, we re-optimised windows of about 30 neighbouring turbines with everything else held fixed, many times over, with OR-Tools CP-SAT through optiwindnet's own model, keeping each change only if the network got shorter and still validated. The same method shortened Hornsea One.1_OSS at capacities 5-12 (PRs #967, #968, #977-#982). On 2026-11-08 we applied it, one search per instance, to the five instances with that profile on London Array.1_OSS and Hornsea Two West: four improved (this one among them), one (London Array.1_OSS capacity 6) did not. Farms whose shortest stored sets are already branched MILP networks (Coastal Virginia, Borssele) gave no meaningful gains.
