# Contributor text, unverified
On large real wind farms the release's best route sets come from CPLEX runs that stopped at their time limit, so we tried improving them locally: re-optimise a window of about 30 neighbouring turbines with everything else held fixed, many times over, with OR-Tools CP-SAT through optiwindnet's own model, keeping each change only if the network got shorter and still validated. In about 40-80 minutes per instance this shortened Hornsea One.1_OSS capacities 8 and 10 (filed earlier as #968 and #967) and, in a later session (2026-11-07), capacities 12 and 5 below every stored route set; at 12 and 5 every independent search seed converged to the identical network. It also shortened London Array capacity 12 below the release's single stored set, but that is not a record: route sets in DTU's earlier dataset (Zenodo 18864643, "London Array legacy"), transplanted onto this instance, are shorter still, so we do not claim it. The same search found nothing on 55-turbine farms (Belwind, CECEP) or on London Array capacities 10 and 11. Each instance is a separate package. Seeded from stored set id 45373 (CPLEX, radial).
