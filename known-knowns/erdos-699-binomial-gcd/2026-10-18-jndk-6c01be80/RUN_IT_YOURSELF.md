From the package root in a fresh shell with Python 3:

```sh
sh verify-it-yourself/run_checks.sh
```

The last line must be `PASS`. To run the independent part alone:

```sh
python3 verify-it-yourself/independent_check.py
python3 verify-it-yourself/verify_algebraic_core_direct.py object/algebraic-core-direct.json
```

The proof is a written mathematical object, not generated by a search. Read object/PROOF.md for all universal steps. Rebuild the supporting algebraic check from its JSON expressions using the included standard-library verifier. No floating point, prime oracle or external dataset is required. Corruption of the frozen object must produce final `FAIL`; a hash failure is an identity check, not a semantic refutation of a revised theorem.
