# METHOD — the two simulators and their highway-capture certificates

Notation: h(u) = heading after u steps (h(0) = 0), pos(u) = ant cell after u steps (pos(0) = (0,0)). Step u+1 reads the colour of pos(u), sets h(u+1) = (h(u) + 1 + 2g) mod 4, flips pos(u), and moves: pos(u+1) = pos(u) + dir(h(u+1)). The "highway" is motion with h(u) = h(u-104) for all large u and 104-step displacement v in {(+-2,+-2)}.

## 1. lantx2 (independent checker, code/lantx2/lantx2.c) — certificate X (PROVED-HERE)
Implementation: byte grid 8192 x 8192 centred on (0,0) (a run that comes within 160 cells of the edge stops as OUT_OF_BOUNDS, never counted as captured); a 104-slot ring holding h(u) at slot u mod 104; L = the last step u with h(u) != h(u-104) (slots 1..103 start as "undefined", so L >= 103); bbox of the box and of every position so far.
1. When h(u) = h(u-104) has held for >= 208 consecutive steps (checked every 64 steps), take a snapshot at the current step s0: B0 = current bbox (it contains the initial box and every cell visited up to s0, hence every cell that is black at time s0 — a black cell is either initially black, so in the box, or was flipped, so visited).
2. Predict period 0 from the ring: headings h*(s0+j) = h(s0+j-104), j = 1..104; cells q_0 = pos(s0), q_j = q_{j-1} + dir(h*(s0+j)); V0 = {q_0..q_103}; v = q_104 - q_0. If v is not (+-2,+-2), no certificate (retry later).
3. M = floor(min(span_x(V0), span_y(V0)) / 2), where span = max - min. K = the least K >= M such that bbox(V0) + K v lies strictly beyond B0 in a coordinate in which v moves away from B0 (then V0 + p v and B0 are disjoint for every p >= K).
4. Keep simulating. If any mismatch occurs (L changes), drop the snapshot. If none occurs up to step s0 + 104 (K+1), the run is CERTIFIED, and T_cap = max(0, L - 103), (vx, vy) = v, dir = h(T_cap).

Why X implies the highway forever. By step 4, periods p = 0..K (steps s0+104p+1 .. s0+104(p+1)) all have the predicted headings, visit V0 + p v in the same order, and start with heading h(s0). For p >= 0 let E_p(c), c in V0, be the colour at time s0 + 104p of the cell c + p v. The headings of period p are determined by its start heading and E_p (at step j of the period the ant reads q_j + p v, whose colour is E_p(q_j) XOR the parity of earlier visits to q_j in this period — the same as in any other period with the same E). Suppose periods 0..p-1 repeat and p >= K. A cell c + p v (c in V0) is outside B0, so it is white at time s0 and was never visited before s0; after s0 it was visited only by periods i < p, each visiting V0 + i v with parity pattern P0 + i v (P0 = cells visited an odd number of times in period 0). So E_p(c) = XOR_{m=1..p} P0(c + m v). A term with c + m v in V0 needs V0 and V0 - m v to overlap in both coordinates, i.e. 2m <= span_x and 2m <= span_y, so m <= M. Hence for p >= K >= M, E_p = XOR_{m=1..M} P0(. + m v), independent of p; in particular E_p = E_K, and period K was observed to repeat, so period p repeats. By induction every period p >= 0 repeats: the motion is 104-periodic from s0 forever, drifting by v, and no black cell of time s0 (in particular no initial black cell) lies in the future sweep V0 + p v, p >= K. Since h(u) = h(u-104) for all u > L (verified up to s0 + 104(K+1), then by the induction) and h(L) != h(L-104), T_cap = L - 103 is the least s with h(u) = h(u-104) for all u >= s + 104: the intrinsic start of periodic motion. It does not depend on how or when the certificate was found.
Stop rule: a run is UNCAPTURED_WITHIN_CAP once L - 103 > cap (T_cap can only grow), or after 4,000,000 steps.
Negative tests (data/validation/negtests.txt): cap just below a known T_cap gives UNCAPTURED; a single black cell planted on the empty-grid highway path at the step-20000 (resp. step-100000) position delays certification past that step (certified at 21120, resp. 107776).

## 2. lant4 (the exhaustive engine, code/lant4pkg) — certificate C(s) (PROVED-HERE; argument also checked by a panel reviewer)
What the code does (code/lant4pkg/src/lant_core.h, lant_run and checkC; same certificate as ref/lant_ref.c). The ring stores pos(u) and h(u) (heading before step u+1). A step u is "periodic" if h(u) = h(u-104) and pos(u) - pos(u-104) is one of (+-2,+-2); runs of consecutive periodic steps with the same displacement are counted. When the run length reaches a multiple of 312 at step t, the code (i) updates the bbox B = bbox of the initial box (widened to contain (0,0)) and of pos(0..t); (ii) rewinds the grid from time t to time s_first (the earliest untested start, at least the run start minus 104) by flipping pos(t-1), pos(t-2), ..., pos(s_first) back; (iii) for s = s_first, s_first+1, ..., t-104 evaluates checkC(s) on the grid G_s of time s, advancing the grid to G_{s+1} (flip pos(s)) after each failed s. So C(s) is evaluated on the grid at time s (with the bbox B of step t). T_cap = the first s for which checkC(s) returns 1. checkC(s) returns 1 only if:
  (a) v := pos(s+104) - pos(s) has |vx| = |vy| = 2 and h(s+104) = h(s);
  (b) with V = (pos(s), ..., pos(s+103)) (the actual cells read by steps s+1..s+104) and P = the set of cells occurring an odd number of times in V: for k = 0, 1, 2, ... until the translate V + k v lies entirely strictly beyond B in some coordinate in which v moves away from B (all x > max_x(B) if vx > 0, all x < min_x(B) if vx < 0, likewise for y), every cell c of V + k v satisfies
        G_s(c) = G_s(c + v) XOR P(c + v).                                        (E_k)
  If a translate would leave the window, or k > 1024, it returns -1 (window overflow: the mask is rerun by the reference program, never counted as captured).

Claim. If checkC(s) returns 1, then for every k >= 0 the steps s+104k+1 .. s+104(k+1) repeat steps s+1..s+104 translated by k v (same headings, cells V + k v, start heading h(s)): the ant moves on the period-104 highway with drift v forever from step s.

Proof.
1. (E_k holds for every k >= 0.) Let k* be the translate at which the loop stopped; E_k was checked for k < k*. For k >= k*, V + k v and V + (k+1) v also lie strictly beyond B in the same coordinate (each further translate moves further away). B contains the initial box and every position up to t >= s + 104, so every cell outside B was white initially and was never visited before step t; in particular G_s(c) = 0 and G_s(c + v) = 0 for c in V + k v. P is supported on V, which lies inside B, so P(c + v) = 0. Hence E_k reads 0 = 0 XOR 0.
2. (Telescoping.) For c in V, E_0 at c, E_1 at c + v, ..., E_{k-1} at c + (k-1) v give
        G_s(c) = G_s(c + k v) XOR P(c + v) XOR P(c + 2v) XOR ... XOR P(c + k v)      (D_k)
   for every k >= 1 (D_0 is trivial).
3. (Period lemma.) Suppose that at step T = s + 104k the ant is at pos(s) + k v with heading h(s), and the colours satisfy G_T(c + k v) = G_s(c) for every c in V. Then steps T+1..T+104 repeat steps s+1..s+104 translated by k v. Proof by induction over j = 0..103: if steps T+1..T+j followed the pattern, step T+j+1 reads the cell pos(s+j) + k v, whose colour is G_T(pos(s+j) + k v) XOR (parity of earlier visits to that cell in this period) = G_s(pos(s+j)) XOR (parity of earlier visits to pos(s+j) in period 0), which is exactly the colour read at step s+j+1; so the turn and the move are the same. At the end the ant is at pos(s+104) + k v = pos(s) + (k+1) v with heading h(s+104) = h(s), by (a).
4. (Induction on k.) Claim I_k: steps s+1..s+104k consist of k translated copies of period 0, and therefore G_{s+104k}(x) = G_s(x) XOR P(x) XOR P(x - v) XOR ... XOR P(x - (k-1) v) for every cell x (period m flips the cells of V + m v with parity P(. - m v)). I_0 is trivial. Assume I_k. For c in V, put x = c + k v: G_{s+104k}(c + k v) = G_s(c + k v) XOR P(c + k v) XOR P(c + (k-1) v) XOR ... XOR P(c + v), which equals G_s(c) by D_k. The ant is at pos(s) + k v with heading h(s) (end of period k-1, or step s itself for k = 0). By the period lemma, period k repeats, which gives I_{k+1}.
5. Hence the motion is 104-periodic from step s forever with drift v in {(+-2,+-2)}. Moreover every future period sees on its cells exactly the colours period 0 saw: on translates beyond B there are no black cells at all (no initial black cell and no debris), and on the finitely many translates inside B the colours were compared cell by cell. This is what bank p1's certificate wording asks for (window repeats shifted by (+-2,+-2); the ant's future sweep holds no black cell that could disturb it). QED.
Remarks. The bbox B is taken at step t >= s + 104, which only makes the check longer (more translates compared), never weaker. checkC returning -1 (overflow) or 0 never produces a capture. Since C(s) implies periodic motion from s, the intrinsic onset of periodicity (lantx2's T_cap, section 1) is <= lant's T_cap; equality is not needed for soundness, and it held on every compared mask: all 65,536 4x4 masks, all 33,554,432 5x5 masks, all 4096 6x6 hard cases and 3 x 2^20 contiguous 6x6 masks (per-mask comparison of lant4 and lantx2 output). In addition, on 3 full 6x6 chunks lantx2 captured every mask with the same chunk maximum, and lantx2's per-sample-unit maximum never exceeds lant's chunk maximum.

## 3. Independence
lantx2 was written from the specification (convention + p1 certificate idea) without opening lant.c, lant2, lant4 or lant_ref sources. Shared: the convention (box mapping, rule, heading, cap) and the definition of T_cap's output columns. Different: data layout (byte grid 8192^2 vs bit planes in a 1024 window), periodicity detection (last-mismatch index vs periodic-run counter tested every 312 steps), and the certificate (simulation until the sweep clears the bbox vs grid translate comparison).

## 4. Random sample rule (frozen before the run)
SEED = 0x5EED20261020. For mask m: z = splitmix64(m + SEED) (z += 0x9E3779B97F4A7C15; z = (z ^ (z >> 30)) * 0xBF58476D1CE4E5B9; z = (z ^ (z >> 27)) * 0x94D049BB133111EB; z ^= z >> 31; all mod 2^64), r = z mod 10000; m is sampled iff r < 100; pass = r div 25 (four independent 0.25% passes). Units = (pass, chunk of 2^24 masks). Per unit lantx2 writes n, CAP, UNCAP, OOB, maxtcap and its mask, sum of T_cap, total simulated steps, and linehash = XOR over captured masks of splitmix64(m ^ tcap<<36 ^ (vx+2)<<60 ^ (vy+2)<<57 ^ dir<<54) (all lantx2 code, function smix).
