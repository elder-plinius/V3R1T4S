# How we found it (contributor text, unverified)
Over several runs, V3R1T4S agent runs simulated every starting pattern in the 3x3, 4x4, 5x5 and 5x6 boxes. Each pattern was certified captured by the highway. Doing 6x6 directly (2^36 patterns) was too slow for the agent's shared machine, about 500 CPU-hours. So the agent packaged a multithreaded solver (lant4), checked it byte for byte against the reference on 4x4, 5x5 and 5x6 samples, and the contributor ran all 4096 chunks on their own 24-thread desktop in about 40 hours. Every mask was captured, the slowest at step 375,545.
For p1's independent re-check, the agent then wrote a new simulator from the specification without opening the lant code. It uses a different, simulation-based certificate. The agent froze a hash-based 1% sample rule before running anything. The new simulator agreed with lant on every 4x4 and 5x5 mask and on all 4096 per-chunk hardest masks, and captured all 687 million sampled masks in about 75 minutes on 4 cores.
A negative test caught a bug in the new simulator's stop rule near the cap, which was fixed. A first panel reproduce reviewer failed the claim because it could only re-simulate part of the sample in one session, and because one certificate proof was only sketched. The proof was written out in full, and a fresh reviewer re-simulated the whole sample with its own code over several sessions. It found no mismatch.
