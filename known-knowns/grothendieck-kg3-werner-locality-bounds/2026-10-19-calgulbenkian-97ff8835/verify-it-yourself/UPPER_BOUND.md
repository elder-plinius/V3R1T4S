# The upper bound L <= 6104, step by step

Notation. ip(x, y) is the Euclidean inner product. A is the 120 x 120 integer matrix in the MATLAB file. `e8_check.py` shows that A = D (3 G - 13 I) D, where G is the Gram matrix of the 120 positive roots r_1, ..., r_120 of E8 (norm 2) in some order and D is a diagonal matrix of signs. D does not change L, so L is the maximum over a, b in {-1,+1}^120 of a^T (3 G - 13 I) b.

1. For fixed b the best a is sign(A b), so L = max_b ||A b||_1.
2. Put w = sum_j b_j r_j (a vector of the E8 root lattice). Then (G b)_i = ip(r_i, w) and (A b)_i = 3 x_i - 13 b_i with x_i = ip(r_i, w). So ||A b||_1 = sum_i |3 x_i - 13 b_i|. (`e8_check.py` tests this identity on pseudo-random b.)
3. Weyl symmetry. Every element g of the Weyl group W maps the root system to itself: g r_i = e_i r_{pi(i)} with e_i = +-1 and r_{pi(i)} positive. Let b' be defined by b'_{pi(i)} = e_i b_i. Then sum_j b'_j r_j = g w and ip(r_{pi(i)}, g w) = e_i ip(r_i, w), so every term |3 x_i - 13 b_i| is unchanged. Hence ||A b||_1 is constant on W-orbits of w, and it is enough to treat dominant w (every orbit has a dominant element).
4. Which dominant w occur. w lies in the zonotope Z = {sum_j t_j r_j : |t_j| <= 1}. The vertices of Z are the points sum_j sign(ip(r_j, u)) r_j for generic u; each is 2 rho' for the positive system chosen by u, i.e. a Weyl image of 2 rho. A norm is convex, so |w|^2 <= |2 rho|^2 on Z. `e8_check.py` computes 2 rho = sum of the 120 positive roots from the data: |2 rho|^2 = 2480. Because b_j is odd, w = sum_j r_j + 2 (root lattice element) = 2 rho + 2 y; and E8 is unimodular (weight lattice = root lattice), so rho and y are in the root lattice and w = 2 v with v in the root lattice and dominant: v = sum_k c_k omega_k with integers c_k >= 0 (c_k = ip(alpha_k, v)), |v|^2 = c^T C^{-1} c <= |rho|^2 = 620. The checker enumerates all such c (18454 of them) from the integer matrix C^{-1}, which has non-negative entries.
5. Dual bound for one w. For any vector mu and any b in {-1,1}^120 with sum_j b_j r_j = w, sum_i |3 x_i - 13 b_i| = sum_i |3 x_i - 13 b_i| + ip(mu, sum_j b_j r_j - w), which equals -ip(w, mu) + sum_i ( |3 x_i - 13 b_i| + b_i ip(r_i, mu) ), and each summand is at most max over s = +-1 of ( |3 x_i - 13 s| + s ip(r_i, mu) ). So ||A b||_1 <= D_w(mu) := -ip(w, mu) + sum_i max_{s=+-1} ( |3 x_i - 13 s| + s ip(r_i, mu) ). If no b has sum_j b_j r_j = w, nothing is to be shown, and a mu with D_w(mu) <= 6104 still exists (a Farkas vector; `dual_certificates.txt` simply contains one).
6. Certificates. For each of the 18454 vectors c, `data/dual_certificates.txt` has a line: c_1 .. c_8, then integers M_1 .. M_8 and q. They define mu through m_k = ip(alpha_k, mu) = M_k / q. The checker computes D_w(mu) exactly in integers from the root coordinates and requires q * D_w(mu) <= q * 6104. It never trusts the file: a line with a bad vector is detected. (In the supplied file q = 1 for every line; two lines reach exactly 6104.)
7. Lower bound. `data/lower_bound_witness.txt` gives a vector b (indexed by the positive roots) for which the checker computes ||A b||_1 = 6104 directly on the matrix in the MATLAB file.

Therefore L = 6104.

What the checker does not prove by itself: steps 3 and 4 are standard facts about the Weyl group and the root zonotope that the checker uses but does not re-derive (it checks their inputs: the 120 roots form the full positive system of an E8 base found among the lines, and |2 rho|^2 = 2480 is computed from the data). A skeptic who doubts step 3 or 4 can instead run the complete enumeration over all b in {-1,1}^120 only in principle (2^120 vectors); the symmetry reduction is what makes the check small.
