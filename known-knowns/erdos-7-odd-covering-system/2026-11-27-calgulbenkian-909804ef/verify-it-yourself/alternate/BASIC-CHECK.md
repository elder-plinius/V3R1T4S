# A short check for the nine-prime branch

Run `python3 verify_nine.py certs/nine_finite.tsv` on the issued table, or `python3 verify_nine.py nine-finite.json` on the companion table. With no argument the program uses the issued table if present, then the companion table. The checker verifies that no covering by distinct odd moduli greater than one on exactly nine primes can have a least common multiple below \(6\,557\,114\,959\,770\,375\). It uses the ordinary basic anchor inequality of [the proof](PROOF.md). It derives all 736 reserves and stage sums from the stated parameters and checks that the 23 accepted cap vectors cover all 5,028 candidate exponent vectors. It uses Python 3.9 or later and the standard library.

Each model gives an exponent upper bound at each of \(3,5,7,11,13,17,19,23,29\). A JSON null means unrestricted. The 32 rows have \(a,c\in\{1,2\}\), \(b\in\{2,4\}\), and \(j\in\{1,2,3,4\}\). They all use the ordinary basic inequality, \(C_7=3/2\), the later thresholds \((4,4,6,8,12,16)\), and the rectangle \(u<9,v<7\) in the companion table. The issued table uses \(u<10\) for the model with \(e_3=12\) and agrees on the other 22 models. This one change integrates the final finite atom at \(u=9\) explicitly. Both choices give valid upper bounds. Both values stored in a row are rational and the reserve must exceed the sum of the seven losses strictly.

## Why the small geometric maximization is exact

Fix a basic state and one pair of height regions in the comparison integral. The live ternary residues in a first-digit branch \(t=1,2\) number
\[
 n_t=9-3\,1_{t=1}-1_{b\bmod3=t}.
\]
They form the same set in each allowed quinary column. In branch \(a\) the column \(a\) has weight zero. In every allowed column the weight of a live ternary residue is constant. Each branch has a complete three-residue block modulo 9. The free residue choices have moduli \(3,9,27,5,15,45,135\).

First fix the ternary branch of each of the six choices with a ternary part, and the column of each of the four choices with a quinary part. In each branch the two choices of ternary depth two can occupy the same full block of three rows. The two choices of depth three can occupy the same single row in that block. This weakly increases the objective in every column at once. To see this, order the rows of a column by their background. Adding a nonnegative amount \(c\) increases \(h(x)=(x-\tau)_+\) by \(h(x+c)-h(x)\), which is nonnegative and nondecreasing. Equivalently, writing the sorted sum of indicators in the first \(k\) rows, its sum is bounded by adding each coefficient times the smaller of \(k\) and its support size. The nested placement attains every such partial-sum bound. For any vector \(s\), its total hinge equals \(\max_k(\sum_{i\le k}s_i^\downarrow-k\tau)\). These assertions also apply to a column in which some of the six choices are absent. The same full block and row work in all columns.

Fix the column of the modulus-5 choice. Within a ternary branch, assign some of the available mixed choices \(15,45,135\) to this column. All the others may be placed together in a heaviest remaining column. On the remaining columns the ternary background is identical row by row. At any row the gain from combining nonnegative additions is at least the sum of their separate gains at the original background. Moving them to a column of maximal weight therefore dominates the old weighted sum of gains. The function `branch_values` maximizes over all splits between these two columns. The function `maximum` enumerates the four possibilities for modulus 5 and every split of the other six choices between the two ternary branches.

At each stage the checker uses the capped height laws from the proof. For multiplier \(m\ge\tau\) the baseline \(m\) makes the hinge affine throughout and its integral uses only mass and first moments. For \(m<\tau\) the program first charges the full linear load, then replaces it by the geometric hinge on every retained height pair. The omitted terms thus have the upper sign. All comparisons use integers or rational arithmetic.

The final enumeration starts from the product of the nine primes and appends extra prime factors in nondecreasing order. Unique factorization gives one visit per vector. A visit succeeds only if the vector fits a model whose 32 inequalities were already verified.
