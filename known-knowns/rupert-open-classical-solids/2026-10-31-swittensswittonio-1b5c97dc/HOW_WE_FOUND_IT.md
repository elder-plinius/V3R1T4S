# How we built it (contributor text, unverified)

Brief: bank partial win p3 asks for a from-scratch exact re-verification of Hervay's RID certificate in a language that is neither Rust nor Python. An agent (C#, .NET) was given only the paper's LaTeX sources, the certificate and the cover JSON files and told not to open Hervay's `proof/src` or `audit/`. It recovered three undocumented conventions from the data (the 8-hex checksum is over the JSON text; vertices are numbered in exact-coordinate sorted order, the reverse numbering also satisfies every Global record but fails the cover witnesses; for `{direction, contact, vertex}` witnesses `vertex` is the plug vertex and `contact` the hole vertex), found and fixed two of its own interpretation bugs, and then had every record accepted. Dead ends: a cyclic-permutation numbering of the vertices (at least 11 of 15 certificate edge pairs were not edges) and a Python brute force for the fold-index order (too slow). A second implementation in JavaScript (not part of this package and not panelled) and a Python checker written by the REPRODUCE skeptic also agreed. See `how-we-built-it/`.
