What will count as the object of a claim (all four are required, otherwise the status is at most PROMISING):
1. A CNF file F_k (k = 20) written by a generator from the definition of the partition problem, and a proof file, such
   that the locally compiled drat-trim (tools/drat-trim, self-tested) prints `s VERIFIED` for (F_k, proof). The sha256
   of both files are recorded from command output.
2. Cross-check on the satisfiable side with the SAME generator: for dom(Q_11), F_19 is satisfied by our explicit
   19-partition (draft PR #954) and F_18 by a known 18-partition, each confirmed by a solver run returning SAT with the
   partition fixed and by decoding the model back to a partition that the independent checker accepts. For tdom(Q_12),
   no 19-partition is known, so the cross-check can only be made at k = 18; this weakness will be stated.
3. A second encoding, written independently in a fresh context from the definition, for which the solver also reports
   UNSAT at k = 20 with a drat-trim VERIFIED proof, and SAT on the same satisfiable cases.
4. A three-skeptic panel.

Everything the generators add beyond the bare constraints is disclosed here, before any run:
- auxiliary variables with full two-way definitions (counters of class sizes, "class contains the set S" indicators);
  they do not restrict the solutions;
- symmetry breaking on class labels by order of first appearance (any partition can be relabelled to satisfy it);
- ONE implied constraint, by double counting: the sum over classes of min(|class|, M) is at most n^2 (M = 7 for
  dom(Q_11), 8 for tdom(Q_12)). It is true for every partition, but it is NOT derived inside the DRAT proof: resolution
  cannot do this counting efficiently. Whether an encoding with this implied constraint meets the bank's wording
  ("a CNF encoding of 'a partition into k classes exists'") is for the CRITERION skeptic to judge; if it does not, the
  result is reported as mathematics plus a machine-checked proof of the rest, not as p2.
Proof construction: lemmas are proved by the solver under assumptions and inserted into one DRAT file in order; every
lemma is checked by drat-trim like any other proof line, so a wrong or unproved lemma makes the check fail. Lists of
small dominating sets are used only to state lemmas; their completeness is not assumed, it is proved by the solver.

A second, weaker artifact may be produced first (never claimed as p2): a DRAT-verified proof that the listed small
dominating sets admit no pairwise disjoint family of the weight a 20-partition needs (set-packing CNF).
