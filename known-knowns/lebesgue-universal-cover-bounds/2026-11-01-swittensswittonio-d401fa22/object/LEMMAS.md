## 0. Conventions and the textbook facts used

* Disc `D = D(0,1/2)`. For odd `n = 2m+1`, corners `V_k = R_n (cos a_k, sin a_k)`, `a_k = 2 pi k/n`, `R_n = 1/(2 cos(pi/(2n)))`. `B_n = intersection_k D(V_k,1)` (Mishra Def 2.6). `eta := pi/(2n)`. `R3 = 1/sqrt3`, `R5 = sqrt((5 - sqrt5)/10)`.
* `S0 = diag(1,-1)`, `rot(a)` = rotation by a about the origin. A *placement* `(t3,rho,t5)` is the arrangement `D`, `B3 + t3`, `rot(rho) B5 + t5` (Def 4.1; B3 un-rotated; B5 rotated about its own centre = the origin of its frame). `A(t3,rho,t5) = area conv(D u (B3+t3) u (rot(rho)B5+t5))`.
* Textbook facts used: (T1) isometries map conv(X) to conv(gX) and preserve area; (T2) area, perimeter monotone under inclusion of convex sets; (T3) a compact convex set is the intersection of its supporting half-planes, and `h_{conv(U K_i)} = max_i h_{K_i}`, `h_{gK}(u) = h_K(g^{-1}u) + <t,u>`; (T4) Green's theorem: area = 1/2 closed-integral (x dy - y dx); (T5) the area of the hull of a disc and an external point decomposes as in L3 (derived in L3 from T3, T4); (T6) the supporting half-plane of a disc at a boundary point contains the disc; (T7) Steiner formula `area(K + eps B) = area K + eps per(K) + pi eps^2` for convex K; (T8) triangle inequality, concavity of sin on [0,pi], product-to-sum identities.

## L1. Hull lower bound

**Statement.** Let `T_1..T_k` be sets of diameter <= 1 and `M(T_1..T_k) = inf over all k-tuples of rigid motions (orientation preserving or reversing) of area conv(U g_i T_i)`. Every convex universal cover `K` (a convex set containing a congruent copy, reflections allowed, of every planar set of diameter <= 1) has `area K >= M`; hence `Lambda = C13b >= M`.

**Proof.** The T_i have diameter <= 1, so there are rigid motions `g_i` with `g_i T_i subset K`. `K` is convex, so `conv(U g_i T_i) subset K`. Area is monotone, so `area K >= area conv(U g_i T_i) >= M` because this particular tuple competes in the infimum. Take the infimum over K. For compact `T_i` the hull is compact, so measurable. QED

Remark. No existence of a minimiser, no compactness of the cover, and no "completion to constant width" theorem is used; only that the test sets (D, B3, B5) have diameter <= 1 (L7). Status: PROVED-HERE.

## L2. Gauge, mirror symmetry, rho in [0, 2pi/5)

**Statement.** For every triple of rigid motions `(g_1,g_2,g_3)` (any may reverse orientation) there is a placement `(t3, rho, t5)` with `rho in [0,2pi/5)` and `area conv(g_1 D u g_2 B3 u g_3 B5) = A(t3,rho,t5)`. Consequently `M(D,B3,B5) = inf { A(t3,rho,t5) : t3,t5 in R^2, rho in [0,2pi/5) }`.

**Proof.**
1. *Mirror.* `D`, `B3`, `B5` (centred at the origin in their standard frames) are each invariant under `S0`: `S0` maps corner `V_k` to `V_{-k}` (angle `-a_k = a_{-k}`), so it permutes the corners and hence maps `intersection D(V_k,1)` to itself (T1; `S0 D(V,1) = D(S0 V,1)`). If `g_i` reverses orientation then `g_i' = g_i S0` preserves orientation and `g_i'(T_i) = g_i(S0 T_i) = g_i(T_i)`. Replace each reversing `g_i` by `g_i'`; the three image sets, hence the hull, are unchanged. (This is per body; there is no "simultaneous reflection" issue.)
2. *Gauge.* Now every `g_i` is `x -> rot(s_i) x + c_i`. Let `h` be the rotation about the origin by `-s_2` composed with the translation by `-c_1` (apply translation first). `h` is orientation preserving; `conv(U h g_i T_i) = h conv(U g_i T_i)` has the same area (T1). Now `h g_1 D` = disc of radius 1/2 centred at `rot(-s_2)(c_1 - c_1) = 0`: it is `D`. `h g_2 B3 = rot(-s_2)(rot(s_2) B3 + c_2 - c_1) = B3 + t3` with `t3 = rot(-s_2)(c_2 - c_1)`. `h g_3 B5 = rot(s_3 - s_2) B5 + t5` with `t5 = rot(-s_2)(c_3 - c_1)`, so `rho = s_3 - s_2`.
3. *Period.* `rot(2 pi/5)` maps `V_k -> V_{k+1}` for the pentagon corners, so it maps `B5 = intersection D(V_k,1)` onto itself; therefore `rot(rho) B5 = rot(rho + 2 pi/5) B5` and `rho` may be reduced mod `2 pi/5` into `[0,2 pi/5)`. `D` and `B3` do not depend on `rho`. QED

**Machine/numerical evidence.** `code/break_L2_gauge_pts.py`: 200 random triples of motions (about half with reflections), the original arrangement vs. the reduced placement, point-set hulls with 20000-gon disc and 3000 points per arc: max |difference| = 3.48e-9 (2.7e-9 on trials with a reflection) = sampling error. `code/break_L2_L4_L5_L6_L8.py`: |A(rho) - A(rho +- 2 pi/5 multiples)| <= 2.6e-12, mirror `A(S0 t3, -rho, S0 t5)` equal to 6.1e-12 (support-function area, N=4000); negative control rho -> rho + pi/5 changes A by 1.2e-2. (The 1.1e-6 gauge number in that file is coarse sampling, superseded by the 3.5e-9 run.)

**Obligation for the checker.** The root box must cover a full period: the stored `rho`-range of the root `[pi/5 - pi/5, pi/5 + pi/5]` (doubles) is 5e-17 short of `[0, 2pi/5]` and the stored translation range `0.7` (double) is 4.4e-17 short of `7/10`. This is repaired by the first widened splits; see L9(d): exact check that the 22 root splits cover `[-7/10,7/10]^2 x [0,2pi/5] x [-7/10,7/10]^2` with virtual ends `7/10` and a rational upper bound of `2pi/5` (Machin series, Fractions) - 0 failures.

## L3. f(d) = area conv(D u {p}), |p| = d >= 1/2

**Statement.** (a) For `d >= 1/2`, `area conv(D(0,1/2) u {p}) = f(d) := (1/4)(pi - arccos(1/(2d))) + (1/2) sqrt(d^2 - 1/4)`. (b) `f'(d) = (1/2) sqrt(1 - 1/(4d^2)) > 0` for `d > 1/2`, so `f` is strictly increasing on `[1/2,inf)`; `f(1/2) = pi/4`. (c) `f(7/10) in [0.836548794348175792634365825494846503795932739403692839104964..., ...]` (60-digit mp.iv enclosure in `out/l3_f.out`), so `f(0.70) > 0.836548794 > 0.8344`. (d) If any placed body of the arrangement contains a point at distance `d >= 1/2` from the origin, then `A >= f(d)`.

**Proof.** (a) Let `r = 1/2`, `p = (d,0)`, `beta = arccos(r/d) in [0,pi/2)`. By T3 the hull `H` has support function `h(theta) = max(r, d cos theta)` (the disc has `h = r`, the point has `h = <p,u>`). For `|theta| < beta`, `d cos theta > r`: the support point is `p`. For `beta <= |theta| <= pi`: `r >= d cos theta`, support point `r u(theta)` on the circle. At `theta = +-beta` the supporting line `{<x,u(beta)> = r}` contains both `p` (since `d cos beta = r`) and `T_+ = r(cos beta, sin beta)`. Hence `bd H` is: segment `p -> T_+`, arc of the circle of radius r from angle `beta` to `2pi - beta` (through pi), segment `T_- -> p`, `T_- = r(cos beta, -sin beta)`. By Green (T4): `2 area = p x T_+ + (arc) + T_- x p` where `p x T_+ = T_- x p = d r sin(beta)` and the arc (radius r, angle span `2pi - 2 beta`) contributes `r^2 (2pi - 2 beta)`; so `area = d r sin(beta) + r^2 (pi - beta)`, and `d sin(beta) = sqrt(d^2 - r^2)` (since `cos beta = r/d`), giving `area = r sqrt(d^2 - r^2) + r^2 (pi - arccos(r/d))`; at `r = 1/2` this is `f(d)` (kite `O T_+ p T_-` of area `r sqrt(d^2-r^2)` plus the sector `r^2 (pi - beta)`, as in the paper). Machine check: sympy finds `Green-area - [r sqrt(d^2 - r^2) + r^2 (pi - acos(r/d))] = 0`; and an independent derivation with the support-function area formula `1/2 int (h^2 - h'^2)` gives the same `f(d)` (difference simplifies to 0) - `out/l3_f.out`.
(b) sympy: `f'(d) = sqrt(4d^2-1)/(4d)`, which equals `(1/2) sqrt(1-1/(4d^2))` (difference simplifies to 0), positive for `d > 1/2`. (By hand: `d/dd[r sqrt(d^2-r^2)] = r d/sqrt(d^2-r^2)`, `d/dd[-r^2 arccos(r/d)] = -r^3/(d sqrt(d^2-r^2))`, sum `r sqrt(d^2-r^2)/d`.) `f` continuous at 1/2 with `f(1/2) = pi/4`. Hence strictly increasing on `[1/2,inf)`.
(c) `mp.iv` (outward rounded intervals; `arccos x` taken as `atan2(sqrt(1-x^2),x)`) at dps 30/60/100 all give lower end `0.83654879434817579263436582549484650379593273940369...` and `lower end - 0.8344 > 0.00214879`. Second, independent, *exact rational* proof without any floating point or library constant: Machin's series (alternating, truncation remainder bounded) gives `pi in [pi_lo,pi_hi]` of width 6e-44, `arccos(5/7) = 2 atan(1/sqrt6)` with `sqrt6` from `isqrt` bounds and the alternating atan series, `sqrt(0.24)` from `isqrt`: the Fraction lower bound of `f(7/10)` is `0.8365487943481758 > 0.836548794` (exact comparison of Fractions asserted). The interval bisection in the same file brackets the root of `f(d) = 0.8344` at `d* = 0.693830648713340803...` (< 0.70), consistent with monotonicity.
(d) The hull contains `D` and the point, hence `A >= area conv(D u {p}) = f(d)` (T2). The centre of `B3 + t3` is `t3` (since `|V_j - 0| = R3 <= 1`, the origin lies in B3), and the centre of the placed B5 is `t5`. So `|t3| >= d` or `|t5| >= d` forces `A >= f(d)`. QED

Numerical break attempt: 300 random d in [0.5,1.6]: max |area(conv(20000-gon inscribed in D + p)) - f(d)| = 1.7e-8 (inscribed polygon, expected inner error); `f` strictly increasing on a 200001-point grid (min step 2.9e-8). Status: PROVED-HERE (+COMPUTED constants).

## L4. Erosion lemma and non-emptiness

**Statement.** Let `V_1..V_n`, `W_1..W_n` be points with `|W_j - V_j| <= delta`, `0 <= delta <= 1`. Then `intersection_j D(V_j,1-delta) subset intersection_j D(W_j,1)`. Moreover the left side is monotone decreasing in `delta` (any upper bound for `delta` may be used). If `V_j` are the corners of a regular `n`-gon with circumradius `R_n` and centroid `c`, then `intersection_j D(V_j,rho) != empty` iff `rho >= R_n` (for `rho in [0,1]`).

**Proof.** If `p` is in the left side then for each j `|p - W_j| <= |p - V_j| + |V_j - W_j| <= (1-delta) + delta = 1`. Monotonicity: `D(V,r') subset D(V,r)` for `r' <= r`. Non-emptiness: if `rho >= R_n` then `p = c` lies in every `D(V_j,rho)` since `|c - V_j| = R_n`. Conversely let `V_j = c + R_n (cos(a_j+phi), sin(a_j+phi))`; then `sum_j (p-V_j) = n(p-c)` (the corners sum to `n c`) hence `sum_j |p-V_j|^2 = n|p-c|^2 + n R_n^2` (sympy confirms for n=3,5: `out/l5_l7_exact.out`), so `max_j |p-V_j|^2 >= R_n^2 + |p-c|^2 >= R_n^2` and a point in the intersection forces `rho >= R_n`. QED

For `delta > 1` the radius `1 - delta` is negative and the set is empty by convention (it is then also `<R_n`). Numerical break attempt: 1,563,600 boundary / near-boundary points of eroded sets (random arbitrary polygons and rotated/translated B3/B5 corner sets; deltas from 1e-6 to 0.6; adversarial `W_j = V_j + delta (V_j - p)/|V_j - p|`): max over `(|p - W_j| - 1)` = 4.4e-16 (rounding; tight case is exactly 0). Status: PROVED-HERE.

## L5. Corner movement and the exact constants

**Statement.** Let a box of placements have centre `(c3, c_rho, c5)` and half-widths `(h3x,h3y; h_rho; h5x,h5y)` with `h_rho <= pi`. (i) Every corner of B3 at any placement in the box is within `delta3 = hypot(h3x,h3y)` of the corresponding corner of B3 positioned at the box centre. (ii) Every corner of the placed B5 is within `delta5 = hypot(h5x,h5y) + 2 R5 sin(h_rho/2)` of the corresponding corner at the box centre. (iii) Any upper bound `>=` these may be used (L4 monotone). (iv) `R3 = 1/sqrt3`, `R5 = sqrt((5-sqrt5)/10)`, `delta3_thr = 1 - R3`, `delta5_thr = 1 - R5` below which the eroded set is non-empty.

**Proof.** (i) The placed corner is `W = V + t3`, the centre one `V + c3` (B3's orientation is fixed): `|W - V_c| = |t3 - c3| <= hypot(h3x,h3y)` because `|t3x - c3x| <= h3x`, `|t3y - c3y| <= h3y`. (ii) `W = rot(rho) V + t5`, `V_c = rot(c_rho) V + c5` for a corner `V` with `|V| = R5` (corners of B5 about its centre). `|W - V_c| <= |t5 - c5| + |(rot(rho) - rot(c_rho)) V|`. The second term: `|rot(a)V - rot(b)V| = 2 R5 |sin((a-b)/2)|` (sympy: `chord^2 - 4R^2 sin^2((rho1-rho2)/2) = 0`), and `|a-b| <= h_rho <= pi` so `|sin((a-b)/2)| <= sin(h_rho/2)` because sin is increasing on `[0,pi/2]`. (iv) Exact values: `R_n = 1/(2 cos(pi/(2n)))` from `2 R_n sin(pi m/n) = 1` (L7(a): `sin(pi m/n) = cos(pi/(2n))`, sympy for n=3,5,7,9). `cos^2(pi/10) = (5+sqrt5)/8` (sympy, exact) gives `R5^2 = 2/(5+sqrt5) = (5-sqrt5)/10`; `R3^2 = 1/3`. QED

Constants (mp.iv, 60 digits, `out/l5_l7_exact.out`): `R3 in [0.57735026918962576450914878050195745564760175127012687601860227, ..242]`, `R5 in [0.52573111211913360602566908484787660728549793224334178152893545, ..560]`, `1-R3 = 0.4226497308103742354908512194980425...`, `1-R5 = 0.4742688878808663939743309151521233...`. The paper's printed `R3 = 0.577350269190`, `R5 = 0.525731112119`, thresholds `0.422649730810`, `0.474268887881` all agree within 5e-13 (asserted; the printed digits are rounded, e.g. printed R3 is above the true value by 3.7e-13). Numerical break attempt: 20000 random boxes (translation half-widths 1e-6..0.5, h_rho 1e-6..0.63) x 6 placements (box vertices and interior): max (actual corner movement - delta) = 3.3e-16 (B3) / -1.3e-15 (B5); adversarial aligned-chord box vertex reaches ratio 0.99999998 for B5 (so the bound is essentially tight and not violated). Status: PROVED-HERE.

## L6. Proposition 4.9 (hull of the eroded cores lower-bounds A on a whole box)

**Statement.** Let `V^(n)_j` be the corners of B3 resp. B5 positioned at the box centre (B3: `V_j + c3`; B5: `rot(c_rho)V_j + c5`), let `delta_n` be any numbers `>= ` the bounds of L5, `C_n = intersection_j D(V^(n)_j, 1 - delta_n)` (empty if `1 - delta_n < R_n`). Then for every placement `(t3,rho,t5)` in the box, `beta(box) := area conv(D u C3 u C5) <= A(t3,rho,t5)`.

**Proof.** The placed bodies are `B3 + t3 = intersection D(W^(3)_j, 1)` with `W^(3)_j = V_j + t3`, and `rot(rho)B5 + t5 = intersection D(W^(5)_j,1)`, `W^(5)_j = rot(rho)V_j + t5` (an isometry maps `intersection D(V_j,1)` to `intersection D(gV_j,1)`). By L5, `|W^(n)_j - V^(n)_j| <= delta_n`, so by L4 `C_n subset` placed `B_n` (empty `C_n` is trivially contained). Hence `D u C3 u C5 subset D u (B3+t3) u (rot(rho)B5+t5)`; taking convex hulls and areas (T2) gives `beta <= A`. QED

(Remark 4.10 of the paper - empty core - is covered: an empty `C_n` contributes nothing; the inequality still holds.) Numerical break attempt, `code/break_L2_L4_L5_L6_L8.py`: 600 random boxes (scale 1e-4..0.2), 8 placements each (vertices and interior), cores sampled exactly along 720 rays by solving the quadratic; max over core points of `(distance to placed corner - 1)` = -4.7e-14; and `beta_inner` (hull of 2048-gon + core points, an inner approximation) minus `A_outer` (support-function outer polygon, N=8000, an upper bound for A) has max -1.2e-4 < 0. Status: PROVED-HERE.

## L7. Reuleaux n-gon = intersection of unit discs about its corners; constant width 1; diameter 1

This is Mishra Def 2.6 + "classical [11,16]". I give a self-contained proof (support function), because it is short and checkable.

**Statement.** `n = 2m+1`, `R = R_n = 1/(2 cos eta)`, `eta = pi/(2n)`, `S := B_n = intersection_k D(V_k,1)`. Then:
(a) `|V_i - V_j| <= 1` for all i,j, with equality exactly when `|i - j| in {m, m+1}` (mod n); all corners lie in `S`, so `P_n = conv{V_k} subset S`.
(b) The support function of `S` is: `h_S(theta) = <V_k,u(theta)>` for `|theta - a_k| <= eta`; `h_S(theta) = <V_j,u(theta)> + 1` for `|theta - (a_j + pi)| <= eta`. (These closed arcs of length `2 eta = pi/n`, centred at all integer multiples of `pi/n`, cover the circle.)
(c) `h_S(theta) + h_S(theta + pi) = 1` for all `theta`: `S` has constant width 1.
(d) `diam S = 1`. `S subset D(0,R)`; the origin lies in `S`.
(e) `S` is invariant under `rot(2 pi/n)` and `S0`.

**Proof.** Chord geometry: `V_{j+s} - V_j = 2R sin(pi s/n) u(a_j + pi/2 + pi s/n)` (sum-to-product), length `c_s = 2R sin(pi s/n)` for `s = 1..n-1`.
(a) `sin(pi s/n)` on `s = 1..n-1` is maximal at `s = m, m+1` where it equals `sin(pi/2 -+ eta) = cos eta`; so `c_s <= 2R cos eta = 1`, with equality exactly at `s in {m,m+1}`. Each `V_i` is within 1 of all `V_j`, i.e. lies in every disc. `S` is convex (T), so `P_n subset S`.
(b) *Upper bounds.* (U1) Let `theta = a_k + psi`, `|psi| <= eta`. `V_k` lies on the unit circles about `C1 = V_{k+m}` and `C2 = V_{k+m+1}` (`s = m, m+1`). The outer unit normals there are `V_k - C1 = u(a_k - eta)` and `V_k - C2 = u(a_k + eta)` (compute the angles from the chord formula: `a_k + pi/2 + pi m/n + pi = a_k - eta` mod 2pi, `a_k + pi/2 + pi (m+1)/n + pi = a_k + eta`). By T6, `S subset D(C1,1) cap D(C2,1) subset {<x - V_k, u(a_k -+ eta)> <= 0}`; and `u(theta)` with `|psi| <= eta < pi/2` is a non-negative combination of these two unit vectors. So `<x - V_k,u(theta)> <= 0` on `S`: `h_S(theta) <= <V_k,u(theta)>`. (U2) `theta = a_j + pi + psi'`, `|psi'| <= eta`: `S subset D(V_j,1)` gives `h_S(theta) <= <V_j,u(theta)> + 1`.
*Lower bounds.* Vertex interval: `V_k in S` gives `h_S(theta) >= <V_k,u>`. Arc interval: put `x = V_j + u(theta)`; if `x in S` then `h_S(theta) >= <x,u> = <V_j,u> + 1`. To show `x in S`: for `l = j + s`, `w = V_l - V_j` has length `c_s` and direction `omega = a_j + pi/2 + pi s/n`; `|x - V_l|^2 = |u - w|^2 = 1 - 2<u,w> + c_s^2 <= 1` iff `cos(omega - theta) >= c_s/2 = R sin a` with `a = pi s/n`. Now `omega - theta = a - pi/2 - psi'` so `cos(...) = sin(a - psi')`. For `|psi'| <= eta`, `a - psi' in [a - eta, a + eta] subset (0,pi)` (since `a >= pi/n = 2 eta`, `a <= pi - 2 eta`); sin is concave on `[0,pi]`, so its minimum over this interval is at an endpoint. Need `2 sin(a -+ eta) cos eta >= sin a` (as `R = 1/(2 cos eta)`); product-to-sum (sympy-verified identities `2 sin(a - eta)cos eta - sin a - sin(a - 2 eta) = 0`, `2 sin(a + eta)cos eta - sin a - sin(a + 2 eta) = 0`) turns this into `sin(a - 2 eta) >= 0` and `sin(a + 2 eta) >= 0`, true because `2 eta <= a <= pi - 2 eta`... precisely `0 <= a - 2 eta` and `a + 2 eta <= pi`. So `x in S`.
(c) For `theta` in the arc interval of index j, `theta + pi` lies in the vertex interval of the same index j (centres `(2j+n) pi/n + pi = 2j pi/n + 2 pi`); then `h(theta) + h(theta + pi) = <V_j,u> + 1 + <V_j,-u> = 1`. Vertex interval k maps to arc interval k symmetrically.
(d) By (c) the width is 1 in every direction. Lemma 2.4 (Mishra; proof: for `x != y`, `|x-y| = <x - y,u> <= h(theta) + h(theta+pi) = width`, and the extreme points in direction theta realise the width) gives `diam S = max width = 1`; so `S` is admissible in L1 (diameter <= 1). Radius: on vertex intervals `h <= R`; on arc intervals `h = 1 - R cos psi' <= 1 - R cos eta = 1/2 <= R`; so `h_S <= R` everywhere and `S subset D(0,R)` (T3). `|0 - V_j| = R <= 1` so `0 in S`.
(e) `rot(2pi/n)` permutes the `V_k` and `S0` maps `V_k -> V_{-k}`. QED

## L9. Bisection, (1+eps) widening, child covers parent

**(a) Real-number lemma.** For `eps >= 0` and an interval `[c-h,c+h]` (`h >= 0`), the intervals `[c - h/2 - (h/2)(1+eps), c - h/2 + (h/2)(1+eps)] = [c - h - h eps/2, c + h eps/2]` and `[c - h eps/2, c + h + h eps/2]` have union `[c - h - h eps/2, c + h + h eps/2] supseteq [c-h,c+h]` (they overlap since `-h eps/2 <= h eps/2`). Other coordinates unchanged, so the two child boxes cover the parent box. By induction on the finite tree (Cor 5.4), the leaves cover the root. Mishra Lemma 5.3; PROVED-HERE (the verifier rejects `eps < 0`, which is necessary: `eps < 0` leaves a gap).

**(b) Schedule independence.** In the verifier the split coordinate is `argmax(h3x,h3y,R5 h_rho,h5x,h5y)` (first maximum) and the child half-width is `(0.5 h)(1+eps)` for either child, so the vector of half-widths at depth d is the same for every node of depth d (induction: children of equal parents have equal half-widths, hence the same argmax). Thus the split coordinate and the half-width of the split coordinate depend only on the depth. `code/l9_cover.py` part A computes the schedule with the verifier's float operations: first 30 splits are coordinates `[0,1,3,4,0,1,3,4,2,0,1,3,4,2,...]`; at split index 62 the half-width is `1.7090e-4`.

**(c) Floating-point semantics (what the interval checker must respect).** The stored child boxes are the *exact real intervals* given by the stored doubles `cL = fl(c - h/2)`, `cR = fl(c + h/2)`, `hC = fl((h/2) lambda)`, `lambda = fl(1 + 1e-11) = 1 + eps'`, `eps' = 1.000000082740371e-11` (`h/2` is exact). Claim: if `h eps' >= u (2|c| + h (1+lambda))`, `u = 2^-53`, then the exact children cover the exact parent: (i) `cL - hC <= c - h`, (ii) `cR + hC >= c + h`, (iii) `cL + hC >= cR - hC`. Proof: `|cL - (c - h/2)| <= u(|c| + h/2)`, `|hC - (h/2)lambda| <= u (h/2) lambda`. (i): `cL - hC <= c - h/2 + u(|c|+h/2) - (h/2)lambda + u(h/2)lambda = c - h - (h/2) eps' + u(|c| + (h/2)(1+lambda))`, which is `<= c - h` iff `(h/2) eps' >= u(|c| + (h/2)(1+lambda))`, i.e. the stated condition. (ii) is symmetric. (iii): `(cL + hC) - (cR - hC) = 2 hC - (cR - cL) >= 2 (h/2)lambda(1-u) - h - 2u(|c|+h/2) = h eps' - u(h lambda + 2|c| + h)`, same condition. QED
The condition holds (with the generous bound `|c| <= cmax + h`, cmax = 0.7, 0.7, 2pi/5, 0.7, 0.7) for **every split index up to 78**; it first fails at index 79 (`out/l9_cover_AB.out`; threshold `h* = 1.554e-5` for translations). `code/l9_depth.py` decodes `cert_B_08344.bin.gz` (sha256 of the uncompressed file `33973342...fdb91f`, matches BRIEF): 4,194,304 blocks, nodes 486,799,600, leaves 245,496,952, forest identity `2L - s = nodes` holds, every block consumed exactly, **deepest split is at index 22 + 39 = 61** (histogram of splits per depth in `out/l9_depth.out`). **(d) Root splits (virtual domain).** The stored root `(c,h) = (0, 0.7)`, `(pi/5, pi/5)` in doubles does not itself contain `Dom` (it is short by 4.4e-17 resp. about 5e-17). ## L10. Leaf soundness: what an accepted leaf proves

**A. Witness leaf.** Let a leaf box `Q` (stored real intervals), `delta_n >=` L5 bounds (any upper bounds), `rho_n = 1 - delta_n`, and `W` a finite set of points such that: (i) disc points `p` with `|p| <= 1/2`; (ii) core points `p` with `|p - V^(n)_j| <= rho_n` for all j, where `V^(n)_j` are the *true real* corners at the box centre; then `area conv W <= beta(Q) <= A` for every placement in `Q` (L6, T2). Proof: `W subset D u C3 u C5`. For an interval implementation the points are exact reals (the stored doubles), and (ii) is certified by `sup |p - V|^2 <= inf rho^2` over the enclosure of `V` (corners computed from enclosures of `R_n`, `cos`, `sin`, `c_rho`, `c5`) and `inf rho = 1 - sup delta` (enclosure of `delta` outward). Ring vertices `(0.5 cos a, 0.5 sin a)` computed in floating point may lie outside `D` by an ulp, so each must be certified `|p|^2 <= 1/4` by an upper bound or shrunk. Dropping a point keeps the claim true (the hull shrinks), so any "retain only if certified" filter is sound; failure to certify costs only area.
**B. A-priori leaf.** If the translation rectangle `[c3x -+ h3x] x [c3y -+ h3y]` has minimal distance `d_min = hypot(max(|c3x| - h3x, 0), max(|c3y| - h3y, 0)) >= d` and `f(d) >= tau`, then every placement in `Q` has `|t3| >= d_min` and `A >= f(|t3|) >= f(d_min) >= tau` (L3 d + monotone), likewise for `t5`. This is the third leaf type the previous skeptic found in `verifyB.box_bound` (it returns `max(a-priori, hull)`); it is sound by Lemma 4.4 and is NOT described in Mishra S5. In the verifier `f_apriori(d) = pi/4` for `d <= 1/2` (a valid lower bound: `A >= area D`).
**C. Shoelace obligation.** A list of points whose `shoelace/2` is claimed as `area conv W` must be certified to be in convex position with winding number one (e.g. a monotone chain: lower chain x strictly increasing with all left turns certified by interval cross products `> 0`, upper chain likewise); then it is a convex polygon with vertices in `W`, shoelace is its area, and `area <= area conv W`. If only a subset of points is used, still a lower bound. Interval arithmetic for the sum with outward rounding gives a rigorous lower bound. (Textbook.)
**D. Fallback.** `core_points` returning None (empty/degenerate) leaves only the a-priori bound; the leaf passes only if that is `>= tau`. Sound (lower bounds only).

Status: PROVED-HERE for A, B, D; C is textbook computational geometry (KNOWN).

## L11. FLAG: the tolerance step of Mishra S5.4 is not correct as stated (harmless; not needed for an exact replay)

Mishra S5.4 retains witness points with `|p - V_j| <= 1 - delta + theta`, `theta = 1e-12`, and claims such a point lies outside `C_n` by at most `eps0 = 1.0016e-12`, then uses `eps0 P + pi eps0^2` (P <= 8.026) as the hull-area loss. In an interval replay where membership is tested exactly (`<= rho` with certified bounds, L10A, no theta) this step is not used at all. Status: GAP (paper text), no effect on the interval claim.
