# INTERVAL_AUDIT.md  — what is certified by interval arithmetic, what is heuristic, what is trusted

Verifier: `LebVerifyI` (C#, dotnet 10), sources `Iv.cs IvConsts.cs Core.cs Program.cs IvTest.cs`.
Labels: PROVED-HERE (follows from the code + the trust base below), KNOWN (textbook / paper lemma), HEURISTIC (selector only; its output is re-certified), TRUST (outside the interval discipline).

## 0. Trust base (TRUST)
1. IEEE-754 binary64 `+ - * /` and `Math.Sqrt` are correctly rounded (round-to-nearest-even) on the executing x64 SSE2 scalar unit; the JIT does not reassociate or use extended precision. Consequence: for exact operands a,b the exact result r satisfies Dn(fl(r)) <= r <= Up(fl(r)) with Up/Dn = next double above/below (`Iv.Up/Dn`, bit-identical to `Math.BitIncrement/BitDecrement`, tested on 2e6 values: `records/ivtest_updn.txt`).
   If a fused multiply-add were contracted, the single rounding error is no larger, so the enclosure still holds.
2. No floating-point *error theorem* is used anywhere (no gamma_n, no Higham bound, no "u = 2^-53" budget). Every inexact operation on the certified path is an `Iv` operation that widens by one ulp each way.
3. The bit-stream decoder (integer code), the forest identity 2L - nseed = nodes and the comparison of doubles by `<` `<=` on exact doubles are exact.
4. Paper lemmas (Mishra arXiv:2608.30538: Lemma 2.3 hull lower bound, gauge/mirror reduction, Lemma 4.4 a-priori bound f(d), Lemma 4.7 erosion, Lemma 4.8 corner movement, Prop 4.9, Reuleaux n-gon = intersection of unit discs about its corners) are NOT re-proved by this program (see the lemma-proofs lens, LEMMAS.md).

## 1. Constants (PROVED-HERE)
`IvConsts.cs` is generated by `tools/gen_ivconsts.py`: mpmath.iv at 70 digits for pi, sqrt 3, R5 = 1/(2 sin 72 deg), R5 cos/sin(72k deg); exact Fractions for 1/n! (n <= 30) and for the exactly known values 0, +-1/2; each rounded outward to doubles by exact floor/ceil (given as raw bit patterns, no decimal parsing). Independently re-checked by `tools/ivtest_check.py` (mpmath.iv at 60 digits): `records/ivtest_check.txt`. Decimal constants 1e-11, 1e-12, 1e-7, 8344/10000 are `Iv.Ratio(p,q)` of exact integers (< 2^53), never parsed literals.

## 2. Operations on the leaf path
| step | arithmetic | status |
|---|---|---|
| child regeneration c +- half, half*(1+inflate) | plain doubles (they DEFINE the child box) | exact doubles, box = real box with those doubles |
| child covers parent (every split: seeds, pre-walk, DFS) | `Prog.Cover`: Iv test of `(c-cL) >= (h-hL)`, `(cR-c)+hR-h >= 0`, `(cL-cR)+hL+hR >= 0` (differences of nearby doubles, so Iv width ~ ulp of the half-width, far below the 1e-11 relative inflation) | Iv, undecided = fail |
| rho top end reaches 2pi/5; bottom reaches 0 | Iv: lower end of (c+h) >= upper end of enclosure of 2*pi/5; upper end of (c-h) <= 0 for every top/bottom seed | Iv |

| a-priori leaf test (box distance >= d0) | Iv: lower end of ax^2+ay^2 >= upper end of d0^2 | Iv |
| erosion radii delta3 = hypot(h3), delta5 = hypot(h5)+2 R5 sin(hr/2), times (1+1e-12) | Iv sqrt / mul; sin by Iv Horner (degree 7 in x^2) + explicit Lagrange remainder |x|^17/17!; R5 enclosure | Iv |

## 3. Heuristics that never carry a claim (HEURISTIC)
`Math.Cos/Sin` direction table; `Cand()` support-point guess `V_jm + RArc*u`; dot-product argmax between bodies; adaptive edge refinement (`Refine`, uses `Math.Sqrt` and plain doubles); corner (circle-circle intersection) candidates; `Widest()` split-coordinate rule and `CIRC5`; midpoints `Iv.Mid`. Each point they output is re-certified by the Iv membership test (or is a cached point certified when registered: the ring of disc D at construction, circle-intersection corners at body registration). A wrong heuristic can only lower the area bound, never raise it.
No library `Sin/Cos/Acos/Atan2/Pow` value enters a certified quantity.

## 4. Reading the result
`RESULT VERIFIED (interval mode)` means: for every leaf, the polygon area lower bound computed with outward-rounded interval arithmetic is >= tau + 1e-12 with tau = 0.8344, and the regenerated leaf boxes are interval-certified to cover the compactified placement domain, CONDITIONAL on the paper's lemmas (section 0.4) and on the trust base (0.1, 0.3).
It is a replay of a published certificate, not a new bound.
