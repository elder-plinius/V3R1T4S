## Z1 (L1). Hull lower bound

**Statement.** For compact `T_1,T_2,T_3` of diameter <= 1, every convex universal cover `K` has `area K >= inf over rigid motions (g_i, reflections allowed) of area conv(U g_i T_i)`; hence `a_Leb >= L := inf_z A(z)` once Z3 holds.
**Proof.** There are rigid motions `g_i` with `g_i T_i subset K`; `K` convex so `conv(U g_i T_i) subset K`; take areas (T2) and the infimum over covers. Zeng's S8.2 phrases this with `Lambda(F)` and `F subset W_1`; the argument is identical and the hierarchy of Part I is not used. QED. Status PROVED-HERE (KNOWN).

## Z2 (L2). Reuleaux n-gon = intersection of unit discs about its corners

Take Definition `R_n^0 := cap_k D(V_k,1)`. Whatever other definition one prefers (union of arcs, completion of the regular polygon), the certificate needs only: (i) `R_n^0` has diameter <= 1 so it is an admissible test set (Z1); (ii) every sample point `p` certified by `|p - V_i| <= 1 for all i` belongs to it (trivial from the definition); (iii) the sampled points are inside the body used. (i) is the theorem proved in `LEMMAS.md` L7: the support function of `S = cap D(V_k,1)` is `<V_k,u>` for `|theta - a_k| <= pi/(2n)` and `<V_j,u> + 1` for `|theta - a_j - pi| <= pi/(2n)`, whence `h(theta) + h(theta+pi) = 1`, and Lemma 2.4 (`|x-y| = <x-y,u> <= width`) gives `diam = 1`; also `S subset D(0,R_n)` and `0 in S`. The circumradius formula `1/(2 sin(floor(n/2) pi/n))` used by the shipped verifier equals `R_n` because `sin(m pi/n) = cos(pi/(2n))` for `n = 2m+1` (sympy, n = 3,5,7,9). Status: PROVED-HERE. Numerics: `out/l7_support_check.out` (n = 3..11: width 1.000000000000000, sampled diameter 1.000000000000000).

Remark on the sample generator (`reuleaux_points`): it takes `c_j + (1 - 1e-12)(cos,sin)(2 pi k/s)` (points slightly inside the arc about the opposite corner `c_j`) and keeps those with `|p - c_i|^2 <= 1` for all i. Soundness needs only the membership test (ii); the `1 - 1e-12` factor and which j generates the point are irrelevant to soundness.

## Z3 (L3). Normalisation

**Statement.** Let `(g_0,g_3,g_5)` be arbitrary rigid motions (each may reverse orientation). Assume the reference bodies are the ones above (vertex of `R_3^0` and of `R_5^0` on the positive x-axis, so `S0 R_n^0 = R_n^0` and `Q_{2pi/n} R_n^0 = R_n^0`). Then there is `z` with `psi in [0,pi/5]` and `area conv(g_0 D u g_3 R_3^0 u g_5 R_5^0) = A(z)`.

**Proof.** Write `g_i x = Lambda_i x + c_i`, `Lambda_i in O(2)`. (1) Apply the global motion `x -> Lambda_0^{-1}(x - c_0)`: `g_0 D` becomes `D` (a disc of radius 1/2 centred at the origin; `Lambda_0^{-1}` preserves it), and the other bodies become `g_i' = (Lambda_0^{-1}Lambda_i, Lambda_0^{-1}(c_i - c_0))`. (2) Apply the global orthogonal map `P := (Lambda_0^{-1}Lambda_3)^{-1}`: `D` is invariant, `R_3` becomes `R_3^0 + c_3''` with `c_3'' = P Lambda_0^{-1}(c_3 - c_0)`, i.e. `T_{c_3''} R_3^0`. No symmetry of `R_3^0` is needed in this step because a global reflection is allowed (areas of hulls are invariant under all Euclidean motions, T1). (3) The pentagon becomes `M R_5^0 + c_5''` with `M := P Lambda_0^{-1} Lambda_5 in O(2)`. If `det M = -1` then `M = Q_psi S0` for some psi and `M R_5^0 = Q_psi (S0 R_5^0) = Q_psi R_5^0`. If `det M = +1`, `M = Q_psi`. So `R_5 = T_{c_5''} Q_psi R_5^0`. (4) `Q_{2pi/5} R_5^0 = R_5^0` (it permutes the corners), so `psi` may be replaced by `psi mod 2pi/5 in [0,2pi/5)`. (5) If `psi > pi/5`, apply the global reflection `S0`: it fixes `D` and `R_3^0` (as sets), sends `T_c R_3^0` to `T_{S0 c} R_3^0`, and `S0 T_c Q_psi R_5^0 = T_{S0 c} Q_{-psi} S0 R_5^0 = T_{S0 c} Q_{-psi} R_5^0`; since `-psi = (2pi/5 - psi) - 2pi/5` the new angle is `2pi/5 - psi in (0,pi/5)` after reducing mod `2pi/5` (step 4). Areas are preserved throughout. QED.

**FLAG F1.** Zeng S9.1 says "the precise initial orientation [of R_3^0, R_5^0] is irrelevant, but it will be kept fixed". That is not true for steps (3) and (5): `S0 R_5^0 = R_5^0` and `S0 R_3^0 = R_3^0` are needed, i.e. both reference bodies must be mirror-symmetric about the x-axis. If `R_5^0` had its symmetry axis at angle `alpha_0`, then `S0 R_5^0 = Q_{2 alpha_0} R_5^0` and the fundamental interval would be `[alpha_0, alpha_0 + pi/5]`, not `[0,pi/5]` (numerical control: `|A(psi = 0.4) - A(reflected)| = 1.7e-3` for an axis at 0.3 rad). The shipped verifier takes `regular_ngon_vertices(n, angle=0.0)` so both bodies have a vertex at `(R_n,0)` and are x-symmetric: the claim holds for the shipped certificate. (Verified in `verifier/geometry.py` line 10-13 and `onebody/core5d` tables.) The same orientation convention is needed in Z5.

Break test (`code/zeng_break.py`, `out/zeng_break.out`): 150 random triples of Euclidean motions (80 reversing the pentagon's orientation map), reduced by exactly the recipe above, area before vs after: max difference 3.6e-9 (sampling error of the inner hulls). Status PROVED-HERE.

## Z4 (L4). Far field

**Statement.** Let `G(rho) = area conv(D u {p})`, `|p| = rho >= 1/2`. (a) `G(rho) = pi/4 + (1/2) sqrt(rho^2 - 1/4) - (1/4) arccos(1/(2 rho))`, `G(1/2) = pi/4`, `G'(rho) = sqrt(4 rho^2 - 1)/(4 rho) > 0` for `rho > 1/2`, so `G` is strictly increasing. (b) For `k in {3,5}`, centre `c` of the placed `R_k` (any orientation) with `r = |c|`, there is a vertex `v` of the placed body with `|v| >= d_k(r) := sqrt(r^2 + R_k^2 + 2 r R_k cos(pi/k))`; `d_k` is strictly increasing on `r >= 0` (`d_k'(r) = (r + R_k cos(pi/k))/d_k(r) > 0`). (c) Hence `r >= b` and `d_k(b) >= 1/2` imply `A(z) >= G(d_k(b))`. (d) `G(d_3(b_3)) > 0.834` for `b_3 = 0.190700` and `G(d_5(b_5)) > 0.834` for `b_5 = 0.194601`, with `R_3 = 1/sqrt3`, `R_5 = 1/(2cos(pi/10))` exact.

**Proof.** (a) Same as LEMMAS.md L3 (Green's theorem on the boundary: tangent segment, far arc, tangent segment), giving `area = r sqrt(rho^2 - r^2) + r^2(pi - arccos(r/rho))`; with `r = 1/2` it equals the displayed formula (`pi/4 - arccos/4` is `(pi - arccos)/4`). Equivalent to Zeng's count "disc + two tangent kites - the sector counted twice" `= pi r^2 + r sqrt(rho^2 - r^2) - r^2 arccos(r/rho)`. sympy: `G' - sqrt(4rho^2-1)/(4 rho) = 0`, `G(1/2) = pi/4` (`out/zeng_consts.out`). (b) The `k` vertices of the placed body, seen from its centre, are `R_k u(phi_0 + 2 pi j/k)`: equally spaced directions (the body is a rigid motion of `R_k^0`, whichever the motion). Some vertex direction is within angle `gamma <= pi/k` of the direction of `c` (if `c = 0` nothing to prove). `|c + v|^2 = r^2 + R_k^2 + 2 r R_k cos(gamma) >= r^2 + R_k^2 + 2 r R_k cos(pi/k)` since `cos` decreases on `[0,pi]` and `gamma <= pi/k < pi`. Monotonicity: sympy `d' - (r + R cos delta)/d = 0`, and the numerator is positive. (c) The vertex `v` is a point of the placed body (corners lie in `cap D(V_j,1)` by Z2/L7(a)), so `conv(D u {v}) subset conv(D u R_3(z) u R_5(z))` and `A(z) >= G(|v|) >= G(d_k(r)) >= G(d_k(b))` using `|v| >= d_k(r) >= d_k(b) >= 1/2` and the monotonicity of `G` and `d_k`. (d) mp.iv at 200 bits with the exact radii (`R_3 = 1/sqrt 3`, `R_5 = 1/(2cos(pi/10))`, `cos(pi/3) = 1/2`, `cos(pi/5) = (1+sqrt5)/4` exact (sympy)): `d_3(b_3) in [0.69267634553793950574120521896699421530477, ...]`, `d_5(b_5) in [0.69267615045354084516685271837435742758939, ...]` (both `> 1/2`),

`G(d_3(b_3)) - 0.834 in [2.139441454410094467857e-7, 2.139441454410094467858e-7]`, `G(d_5(b_5)) - 0.834 in [1.464388840437641856899e-7, 1.464388840437641856900e-7]`,

both strictly positive (`out/zeng_consts.out`). QED.

**Consequence (Zeng Lemmas S10.2, S10.3, Prop S10.4).** If `A(z) <= 0.834` then `||c_3|| < b_3` and `||c_5|| < b_5`; so `|x_3|,|y_3| < b_3`, `|x_5|,|y_5| < b_5` and `z in Omega_coarse = [-b_3,b_3]^2 x [0,pi/5] x [-b_5,b_5]^2`. (Actually `A > 0.834` strictly whenever `||c_k|| >= b_k`.)

## Z5 (L5). Collar reduction

**Statement.** Let `a_0 = 0.08`. Define `C_n = [a_0, b_n] x [0, pi/n]` (polar coordinates `(r,theta)` of the centre), `W_n(r,theta) := area conv(D u (u(theta) r + R_n^0))`. If `W_3 >= 0.834` on `C_3` and `W_5 >= 0.834` on `C_5`, then every `z in Omega_full = R^2 x [0,pi/5] x R^2` with `A(z) < 0.834` lies in `Omega_core = [-0.08,0.08]^2 x [0,pi/5] x [-0.08,0.08]^2`.

**Proof.** Let `A(z) < 0.834`. By Z4, `||c_3|| < b_3`, `||c_5|| < b_5`. Suppose `z notin Omega_core`: since `psi in [0,pi/5]`, some coordinate of `c_3` or `c_5` has absolute value `> a_0`, so `r_k = ||c_k|| >= ||c_k||_inf > a_0` for that k, `r_k in [a_0,b_k)`. R_3 case: `R_3(z) = T_{c_3} R_3^0`, so the one-body hull is `conv(D u (c_3 + R_3^0))`, `c_3 = r u(theta_3)`. The dihedral group `D_3` (rotations by `2pi/3`, reflection `S0`, all fixing `D` and `R_3^0` as sets by F1) acts: for `g in D_3`, `g(D u (c + R_3^0)) = D u (g c + R_3^0)`, hence `W_3(r,theta)` is invariant under `theta -> theta + 2 pi/3` and `theta -> -theta`; every angle is equivalent to one in `[0,pi/3]` (reduce mod `2pi/3`, then reflect `theta -> 2pi/3 - theta` if `> pi/3`). R_5 case: `R_5(z) = T_{c_5} Q_psi R_5^0`; apply the global rotation `Q_{-psi}` (fixes `D`, preserves areas) to get `conv(D u (Q_{-psi} c_5 + R_5^0))`, a body in reference orientation with centre direction `theta_5 - psi`; then use `D_5` as before to move the direction into `[0,pi/5]`. In both cases `A(z) >= area conv(D u R_k(z)) = W_k(r_k,theta') >= 0.834` by hypothesis (adding the other body can only enlarge the hull, T2), contradicting `A(z) < 0.834`. QED

Numerics: 300 random `(n,r,theta)`: `max |W_n(r,theta) - W_n(r,theta_reduced)| = 2.3e-9` (`out/zeng_break.out`). The ends: the collar domain is `theta in [0, pi/n]` with the TRUE `pi/n`; the shipped boxes stop at `float(pi/3)` and `float(pi/5)` (below the true ends by 1.1e-16 and 2.4e-17) - the replay bridges this by extension to an outward enclosure of `pi/n` (report section 2). The core domain's `psi in [0,pi/5]` has the same issue and the same repair. Status PROVED-HERE (+ F1).

## Z6 (L6). Local certificate lemmas

Setting: box `B` of parameters, polygon `P(z) = [p_1(z),...,p_m(z)]` with fixed vertex labels, `m >= 4` (a degenerate triangle has `S = 0`; for `m = 3`, `S > 0` already means a non-degenerate triangle, so everything below holds), `p_i(z) in D u R_3(z) u R_5(z)` for all `z in B`.

**(a) Polygon in hull.** `conv{p_i(z)} subset conv(D u R_3(z) u R_5(z))` by monotonicity of conv. Hence `A(z) >= area conv{p_i}`. (If the filled region `Omega(z)` of a simple polygon with these vertices lies in `conv{p_i}`, then `A >= area Omega`; see (b).)

**(b) Simple polygon: filled region inside the vertex hull and area = shoelace.** Suppose every pair of non-adjacent edges is disjoint (certified by interval separation for all `z in B`), `m >= 4`, and `S(z) > 0` where `S = (1/2) sum_i (x_i y_{i+1} - y_i x_{i+1})`. *Step 1: adjacent edges meet only at their common vertex and no edge is degenerate.* If `p_i = p_{i+1}`, then edges `e_{i-1}` and `e_{i+1}` (non-adjacent as `m >= 4`) both contain `p_i`: contradiction. If adjacent edges `e_{i-1}=[p_{i-1},p_i]`, `e_i=[p_i,p_{i+1}]` overlapped in more than `p_i`, they would be collinear on the same side of `p_i`, so `p_{i+1} in e_{i-1}` or `p_{i-1} in e_i`; the first puts `p_{i+1}` in `e_{i-1} cap e_{i+1}`, the second puts `p_{i-1}` in `e_{i-2} cap e_i` (both pairs non-adjacent for `m >= 4`): contradiction. So the closed polygon is a simple closed curve (T4). *Step 2:* by T3, `S = +area(Omega)` or `-area(Omega)` according to orientation; `S > 0` gives `S = area(Omega)` (ccw). *Step 3: `Omega subset K := conv{p_i}`.* `bd Omega subset K`. If `x notin K`, a separating line gives a ray from `x` to infinity that misses `K`, hence misses the curve; so `x` is in the unbounded component of the complement, i.e. `x notin Omega`. Therefore `S(z) = area Omega <= area K <= A(z)` (T2). So `S(z) >= 0.834` on `B` implies `A(z) >= 0.834` on `B`. QED. (The paper's wording "spikes along adjacent edges have zero area" is not needed because Step 1 excludes spikes.)

**(c) Convexity from turn margins and rotation index one (paper Lemma S13.2 and its homotopy).** *Claim 1.* Let `p_1..p_m` be a closed polygon with edge vectors `e_i = p_{i+1} - p_i != 0` and exterior angles `phi_i in (0,pi)` (the argument of `e_{i+1}` relative to `e_i`, `phi_i = atan2(det(e_i,e_{i+1}), <e_i,e_{i+1}>)`) with `sum_i phi_i = 2 pi`. Then the `p_i` are in strictly convex position and listed counter-clockwise. *Proof.* Fix i; rotate coordinates so `e_i` points along +x. Let `alpha_k in (0,2pi)` be the argument of `e_k` for `k = i+1,..., i-1` (cyclically), strictly increasing because the `phi` are positive and their total from `e_i` to `e_{i-1}` is `2pi - phi_{i-1} < 2pi`; also `alpha_{i+1} = phi_i in (0,pi)` and `alpha_{i-1} = 2pi - phi_{i-1} in (pi,2pi)`. The y-coordinate of `p_j` relative to `p_i` is the partial sum `y_j = sum |e_k| sin(alpha_k)` of terms that are `> 0` while `alpha_k < pi`, possibly one `0` at `alpha_k = pi`, then `< 0`: the sequence `y_j` increases then decreases, starts at `y_i = 0`, and returns to `y_i = 0` (closure). So all `y_j >= 0`, and in fact `y_j > 0` for `j notin {i,i+1}`: the first step `sin alpha_{i+1} > 0` makes `y_{i+2} > 0`, and the last step has `sin alpha_{i-1} < 0` makes `y_{i-1} > 0`; a unimodal sequence between them is `>=` the smaller end value `>0` (the intermediate values of an increasing-then-decreasing sequence are at least the minimum of its first and last terms). So every other vertex lies strictly to the left of every edge line; each polygon edge is therefore an edge of `conv{p_i}`, all `m` points are vertices of the hull, and the polygon is its boundary traversed ccw. QED. *Claim 2 (homotopy).* Suppose for the centre polygon `c = (p_i(c_B))` all `det(e_i,e_{i+1}) > 0` and total turning `2 pi` (e.g. a cyclic subsequence of the vertices of a strictly convex polygon listed ccw; or certify the rotation index directly, see below). Suppose for every choice of points `q_i` in the balls `|q_i - p_i(c_B)| <= eps_i` all consecutive dets `det(q_{i+1}-q_i, q_{i+2}-q_{i+1})` are `> 0` (this is what the replay certifies; it also forces `q_{i+1} != q_i`). For `z in B` put `d_i = p_i(z) - p_i(c_B)`, `|d_i| <= eps_i` (needs `eps_i >= sup |p_i(z) - p_i(c_B)|`; for the core, `p = T_t Q_psi p_0`: `|p(z) - p(c)| <= |Delta t| + |p_0||Delta psi|` by T6, and `|Delta t| <= hypot(r_x,r_y)`), and `q_i(t) = p_i(c_B) + t d_i`, `t in [0,1]`. All `q_i(t)` stay in the balls (convexity of the ball), so all `det > 0` along the path and every `phi_i(t) in (0,pi)` is a continuous function of `t` (the angle is continuous on `{det > 0}`). `sum_i phi_i(t) in 2 pi Z` because the polygon closes up (the direction returns to `e_1`), and a continuous function with values in `2piZ` is constant. At `t = 0` the sum is `2 pi`; hence at `t = 1`, and Claim 1 shows `P(z)` is strictly convex ccw. *Certifying the index at the centre.* If all `det > 0` (each `phi_i in (0,pi)`) then `sum phi_i = 2 pi k`; `k` equals the number of steps from an edge with `y < 0` to an edge with `y > 0` (ccw rotation by `< pi` from the lower to the upper half plane crosses the +x direction, the argument increases monotonically, and each full turn crosses +x exactly once), which is what the replay's `RotIndexOne` counts (edge y-signs strictly certified nonzero; `0` means fail). This replaces the paper's unverified "rotation index one follows from the hull construction" (their D6) by a certificate. *Numerical test of Claim 1* (`code/zeng_break_l6.py`, `out/zeng_break_l6.out`): of 60000 random polygons, 7636 had all turns positive; of these 1285 had total turn `4 pi` and 95 `>= 6 pi` (non-convex), and **0** violations of "total turn `2 pi` iff convex in the given order"; the pentagram (all dets `> 0`, total `4 pi`) shows the index condition cannot be dropped. Status PROVED-HERE; Claim 1 is the standard turning-number criterion, proved above.

**(d) Perturbation bound (exact expansion).** Let `p_i = v_i + d_i`, `|d_i| <= eps_i`, `v_i = p_i(c_B)`. Then
`S(p) - S(v) = (1/2) sum_i [ det(v_i,d_{i+1}) + det(d_i,v_{i+1}) + det(d_i,d_{i+1}) ]`.
Regroup the linear terms by the index of `d`: `d_i` appears in `det(d_i, v_{i+1})` (from term i) and in `det(v_{i-1}, d_i) = -det(d_i, v_{i-1})` (from term i-1), giving `(1/2) sum_i det(d_i, v_{i+1} - v_{i-1})`. Hence, with `|det(a,b)| <= |a||b|`:
`S(p) >= S(v) - (1/2) sum_i eps_i |v_{i+1} - v_{i-1}| - (1/2) sum_i eps_i eps_{i+1}`.
This is exactly the quantity `E = sum eps_i|v_{i+1}-v_{i-1}|/2 + sum eps_i eps_{i+1}/2` in the replay (`LeafCheck.cs`, `EvalTemplate`). sympy (m = 5, symbolic): `S(c+d) - S(c) - [1/2 sum det(d_i,c_{i+1}-c_{i-1}) + 1/2 sum det(d_i,d_{i+1})] = 0` (`out/zeng_consts.out`). NUMERICAL: 20000 random polygons (m = 3..11), adversarial displacement `d_i = -eps_i grad/|grad|` and random displacements: min `S(z) - bound = +4.99e-12` (it is `~0` at the adversarial point, i.e. the bound is tight to second order and never violated); expansion-identity residual 5.2e-16. (First run of this test had a bug in the random displacement norm; fixed, rerun, see `out/zeng_break.out` note.) Status PROVED-HERE.

**(e) Mean-value bound.** `S` is a polynomial in the vertex coordinates, which are smooth functions of `z` (`p = c_k + const` for translated points, `p = T_t Q_psi p_0` for pentagon points, `p_0` a fixed table point, so `C^infinity`), so `S` is `C^1` on the (convex) box. For `z in B`: `S(z) - S(c_B) = int_0^1 grad S(c_B + t(z - c_B)) . (z - c_B) dt >= - sum_k (sup_B |dS/dz_k|) r_k` because `|z_k - c_k| <= r_k` and the segment stays in `B`. Chain rule: `dS/dx_i = (1/2)(y_{i+1} - y_{i-1})`, `dS/dy_i = -(1/2)(x_{i+1} - x_{i-1})` (sympy-checked), `dp/dx_3 = (1,0)`, `dp/dy_3 = (0,1)` for R_3 vertices, same for `x_5,y_5` on R_5 vertices, `dp/dpsi = Q_psi J p_0` (`J` = rotation by `pi/2`; sympy: `d/dpsi (Q q) - Q J q = 0`) for R_5 vertices, `0` for disc vertices. The replay accumulates exactly these (`D[0] += dy/2, D[1] -= dx/2` with `dx,dy` = neighbour difference of the interval box vertices, and the psi-term with interval `cos, sin`), then uses `MaxAbs` of each `D[k]` times the half-width `rad[k]`. **FLAG F2:** the paper (S13.4) writes `G_k >= sup dS/dz_k` without absolute value; that is insufficient when a partial is negative. The replay correctly bounds `sup |dS/dz_k|` (`G_k >= MaxAbs`, line 237/252 of LeafCheck.cs). NUMERICAL: 300 random core boxes (radii 1e-4 to 0.03), template = hull of the centre configuration (ccw), sampled sup of `|dS/dz_k|` (not rigorous), 12000 random `z`: min `S(z) - [S(c) - sum G_k r_k] = +2.3e-5`. Status PROVED-HERE.

**(f) Vertex membership for samples.** For core: `p_i(z) = T_t Q_psi p_0` with `p_0` a table point in `R_n^0` (certified by `|p_0 - V_j| <= 1` for all j with outward-rounded arithmetic) lies in `T_t Q_psi R_n^0 = R_n(z)` (isometry image); disc points `|p|^2 <= 1/4` certified; collar: `p = c(r,theta) + p_0` likewise. ## Z7. Assembly

**Theorem.** Assume (i) `G(d_3(b_3)) > 0.834`, `G(d_5(b_5)) > 0.834` (Z4, COMPUTED); (ii) `W_n >= 0.834` on `C_n` (n = 3, 5) with the true angular upper ends `pi/n` (collar leaves, exact partition of `[0.08,b_n] x [0,pi/n]` verified by the replay with the end bridge); (iii) `A >= 0.834` on `Omega_core` with the true `pi/5` (core leaves, exact partition verified). Then `a_Leb >= 0.834`.
**Proof.** Let `z in Omega_full`. If `||c_3|| >= b_3` or `||c_5|| >= b_5`: `A(z) > 0.834` (Z4). Else if `z notin Omega_core`: Z5 gives `A(z) >= 0.834` (contrapositive form).
