# How we built it (contributor text, unverified)

Brief: bank partial win p1 asks for an independent replay of one of the 2026 lower-bound certificates with outward-rounded interval or exact arithmetic. An earlier attempt on Mishra's 0.8344 certificate used binary64 with a hand-proved error bound and lost the criterion skeptic on the arithmetic wording; this run redid the idea with a literal interval type. An agent wrote a C# checker with its own `Iv` type (every + - * / sqrt result widened one ulp each way), interval Taylor sin/cos, exact integer box partitions, and sample-point tables from mpmath.iv re-verified in C#. It replayed all 6,746,392 leaves of Zeng's Zenodo certificate. Along the way it found that the published verifier silently drops one near-vertex sample point under python-flint 0.9.0, so a checker using the complete point set needed a second polygon variant on 0.035% of core leaves; that the paper's perturbation bridge for the angular end points is described but not implemented; that the shard-set hash only matches with a path prefix; and that the paper's far-field margins use non-enclosing float radii. Dead ends: trusting the recorded lower bounds (not independent), exact-rational leaf proofs (irrational sample points, no gain over outward intervals), bit-for-bit reproduction of the recorded template bounds. A separate lemma lens wrote the analytic layer as proofs (`object/LEMMAS_ZENG.md`), and a fresh panel of three skeptics checked the claim; the REPRODUCE skeptic wrote a second, different interval checker (mean-value bounds with bisection) that also accepted every leaf.
