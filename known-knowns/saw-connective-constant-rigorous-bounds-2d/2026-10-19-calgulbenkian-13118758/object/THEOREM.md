# The pocket-pruned automaton bound: statement and proof

Notation. G is the 4.8^2 lattice with the coordinates of AUTOMATON.md. c_n is the number of n-step self-avoiding walks (SAWs) on G from a fixed vertex o, mu = lim c_n^(1/n) (it exists; G is connected, locally finite and vertex-transitive). Aut(G) contains the 8 symmetries about the origin and the translations by 3Z^2. A state is a canonical walk S = (u_0, ..., u_(L-1)) (distinct vertices, consecutive ones adjacent); V(S) is its vertex set, head(S) = u_(L-1).

## 1. Statement

**Theorem.** Let S_0, ..., S_(N-1) be the states, and for each state S_i and each kept move A (a neighbour of head(S_i) not in V(S_i) that passes both pocket tests of AUTOMATON.md) let t(i, A) be a candidate target of AUTOMATON.md, chosen in any way. Let P be the N x N matrix with P[i][j] = number of kept moves A of S_i with t(i, A) = j (moves pruned by a pocket test contribute nothing). If x is a vector of positive numbers and lambda = max_i (P x)_i / x_i, then mu <= lambda.

The checker computes lambda exactly (a rational number) for the shipped vector and for the choice "smallest vector entry among the candidates".

## 2. Ingredients

**(SI) Ordered subset inclusion (checked by the program on every candidate it examines).** For a state S, a neighbour A of head(S) not in V(S), ex = (u_0, ..., u_(L-1), A), and a candidate target T, there are indices j_0 < j_1 < ... < j_(r-1) = L (the index of A) and sigma in Aut(G) (a symmetry about the origin composed with a translation by 3Z^2) with T_t = sigma(ex[j_t]) for all t. In words: the target is an automorphic image of a subsequence of ex, keeping the order and the new head. The candidates of AUTOMATON.md are of this form by construction (suffix pruning drops an initial segment; a chord shortcut drops a middle segment; canonicalisation applies sigma); the checker re-derives the indices and sigma for every candidate in the state set and every second-pass candidate, independently of the canonicalisation routine, and reports 0 failures.

**Lemma R (monotone rays).** In G every vertex has a neighbour with strictly larger x and a neighbour with strictly smaller x (checked by the checker for the four vertex types; neighbour offsets depend only on type). Hence from any vertex p and any set F of vertices all of whose x-coordinates are at most x(p), there is an infinite path p = q_0, q_1, q_2, ... with strictly increasing x such that q_1, q_2, ... avoid F (the initial vertex p itself may lie in F; when p is not in F the whole path avoids F). Symmetrically for smaller x.

**Lemma B (bridges).** A bridge is an n-step SAW (w_0, ..., w_n) with x(w_0) < x(w_i) <= x(w_n) for all 1 <= i <= n. Let b_n(v) be the number of n-step bridges from v. Then lim b_n(v)^(1/n) = mu for every vertex v.
Source: G. R. Grimmett and Z. Li, "Locality of connective constants" (https://www.statslab.cam.ac.uk/~grg1000/papers/loc-6.pdf; fetched and read by the builder, see table-record/FETCHLOG.txt), Section 3 Definition 3.1, Section 4 (bridge definition (4.1)), Proposition 4.2 and Theorem 4.3 (Bridge theorem): for an infinite, connected, quasi-transitive, locally finite, simple graph with a unimodular graph height function (h, H), the bridge constant beta = lim (min_v b_n(v))^(1/n) equals mu, and b_n(v)^(1/n) -> beta for every v (Proposition 4.2). Their bridge definition (4.1), h(pi_0) < h(pi_i) <= h(pi_n) for 1 <= i <= n, is ours with h = x. Hypotheses, checked one by one against the text read:
- G is infinite, connected, locally finite (degree 3) and simple: yes.
- h(v) = x(v) - x(o) (so h(o) = 0, Definition 3.1(a)) takes integer values.
- H = the group of translations v -> v + (3a, 3b), a, b integers; these are automorphisms of G (checked by the checker) and H acts quasi-transitively with exactly four orbits (vertex types E, W, N, S).
- h is H-difference-invariant: h(alpha v) - h(alpha u) = x(v + t) - x(u + t) = h(v) - h(u). Yes (Definition 3.1(b)).
- Every vertex has a neighbour of strictly greater and one of strictly smaller height (Definition 3.1(c)); this is Lemma R's property, checked.
- H acts freely (a non-trivial translation fixes no vertex), so every stabiliser is trivial and |Stab_u v| = |Stab_v u| = 1: the action is unimodular (equation (3.1)).
Hence Theorem 4.3 gives beta = mu, and Proposition 4.2 gives the limit for every starting vertex, in particular for o. No reflection or unfolding argument is needed. (The x-coordinate here is the coordinate of AUTOMATON.md, in which the horizontal and vertical edges are the links between the squares; bridge growth does not depend on that picture, only on h.)
Earlier general references (Hammersley-Welsh 1962 for Z^d, Kesten 1963) are the historical source; Jensen 2004 (cond-mat/0409381) uses the same bridge definition on the 4.8^2 lattice.

## 3. The key lemma: bridges pass both pocket tests

**Lemma P.** Let W = (w_0, ..., w_n) be a bridge, and suppose that at step m (1 <= m < n) the following holds: there is tau in Aut(G) and indices 0 <= j_0 < j_1 < ... < j_(L-1) = m with S_t = tau(w_(j_t)) for the current state S = (S_0, ..., S_(L-1)). Let A = tau(w_(m+1)). Then A passes test 1 and test 2 of AUTOMATON.md for the state S.

Proof. Automorphisms preserve connectivity and infinity of components, so we may argue in the frame of W (replace S by tau^(-1) S, a subsequence of W in order).
Test 1. The removed set is V(S), contained in {w_0, ..., w_m}. The vertices w_(m+1), ..., w_n are not in {w_0, ..., w_m} (W is self-avoiding), and consecutive ones are adjacent, so w_(m+1) is joined to w_n by a path avoiding V(S). By the bridge property every vertex of W has x <= x(w_n), so by Lemma R there is an infinite path from w_n with increasing x whose vertices after w_n avoid all of W. Here V(S) is contained in {w_0, ..., w_m}, which does not contain w_n (n > m), so the ray from w_n of Lemma R avoids V(S) after its first vertex and its first vertex w_n is not in V(S) either. Joined, this is an infinite connected set containing w_(m+1) and avoiding V(S). So the component of A in G minus V(S) is infinite and the move is kept.
Test 2. The tested vertex is S_0 = tau(w_(j_0)) and the removed set is {S_1, ..., S_(L-1), A} = tau of {w_(j_1), ..., w_(j_(L-1)), w_(m+1)}, all with indices greater than j_0. The vertices w_(j_0 - 1), ..., w_0 have smaller indices, so they are not in the removed set, and w_(j_0) is joined to w_0 by a path avoiding it (if j_0 = 0 the path is the single vertex). By the bridge property x(w_0) < x(w_i) for i >= 1, so by Lemma R there is an infinite path from w_0 with strictly decreasing x whose vertices after w_0 avoid every vertex of W. Hence the component of S_0 is infinite and the move is kept. QED

(The test is applied to the state, a subset of the walk, so the removed sets are subsets of the sets used above; removing fewer vertices only enlarges components. The orderedness of the state, which is what (SI) adds to the older unordered version, is exactly what test 2 needs: the oldest vertex of the state must have all other state vertices later in the walk.)

## 4. Proof of the Theorem

Fix a vertex o and a bridge W = (w_0 = o, ..., w_n) of n steps. Its first edge (w_0, w_1) is equivalent under Aut(G) to one of the two seed states (the checker verifies that all directed edges fall into two classes, which are the two seeds, using the vertex-transitivity of G under the group generated by the symmetries and 3Z^2 translations on a window and periodicity). Let tau_1 carry it to the seed S_(i_1), i_1 in {0, 1}.
Induction on m = 1, ..., n: there are a state index i_m and tau_m in Aut(G) and indices j_t with S_(i_m)'s t-th vertex equal to tau_m(w_(j_t)), j_t increasing, last index m. (This is the hypothesis of Lemma P.) For m = 1 it holds with j = (0, 1). Step m to m+1 (m < n): A = tau_m(w_(m+1)) is a neighbour of the head, not in V(S_(i_m)) because W is self-avoiding and V(S_(i_m)) lies in tau_m{w_0..w_m}. By Lemma P the move A is kept. Its chosen target T = S_(i_(m+1)) satisfies (SI) for ex = S_(i_m) + [A]: T_t = sigma(ex[k_t]), k_t increasing, last index the new head. Put tau_(m+1) = sigma composed with tau_m. Then the vertices of T are tau_(m+1)(w) for an increasing subsequence of w_0..w_(m+1) ending in w_(m+1), which is the induction hypothesis at m+1.
So W gives a sequence of kept moves (i_1, A_1), ..., (i_(n-1), A_(n-1)), a path of n-1 steps in the multigraph of P starting at i_1. Injectivity. Partition the bridges from o by their first directed edge (w_0, w_1): there are 3 such edges. For each first edge fix once and for all one automorphism tau_1 carrying it to its seed state, and fix, for every selected (state, move) pair, one witnessing automorphism sigma of (SI). Within one class the whole sequence tau_1, tau_2, ... is then a function of the transition path (tau_(m+1) = sigma(i_m, A_m) composed with tau_m), so w_(m+1) = tau_m^(-1)(A_m) is recovered from the path; distinct bridges of the class give distinct paths. Different classes may map to the same seed, but they are counted separately.
Therefore the number of n-step bridges from o is at most the sum over the 3 first edges of (P^(n-1) 1)_(seed of that edge), at most 3 * max over seeds s of (P^(n-1) 1)_s. If x > 0 and P x <= lambda x componentwise (P has non-negative entries) then P^k x <= lambda^k x and (P^k 1)_s <= lambda^k x_s / min x. So b_n(o) <= 3 lambda^(n-1) max x / min x for every o (the same for every start vertex), hence b_n(o)^(1/n) <= (3 max x / min x)^(1/n) lambda^((n-1)/n) -> lambda. By Lemma B, mu = lim b_n(o)^(1/n) <= lambda. QED

## 5. What is and is not claimed
- The bound rests on (SI) for the chosen targets, on the pocket tests being the stated tests (an infinite-component test, exact as explained in AUTOMATON.md), and on Lemma B, the Bridge theorem of Grimmett and Li, whose hypotheses are verified above.
- Test 1 and 2 are tested on the state, not on the whole walk: this is the point of the ordered invariant. Unordered inclusion alone would not suffice for test 2 (the oldest vertex of the state must be a vertex whose predecessors in the walk lead back to the start).
- Nothing is claimed about automata for other loop lengths, and nothing about non-bridge walks: the pruned automaton does NOT count all SAWs (it drops walks whose head enters a finite pocket or whose recent start is enclosed), so P is not a bound for c_n; it is a bound for bridges only.
- Why lambda is only an upper bound for mu and no approximation is claimed: the automaton also forgets old vertices (admitting extra walks) and uses a possibly non-optimal vector.
- Unreachability of the search cap. A stored state has at most 33 edges (a state with L >= 2 vertices satisfies (L - 1) + dist >= L, so L <= 34), so an extended window has at most 35 vertices, and the removed set plus the tested vertex span at most 34 steps in each coordinate, that is at most 35 integer positions per coordinate; the box enlarged by 2 on each side has at most 39 positions per side. The search stops when it pops a vertex outside this box, and every vertex discovered before that lies within one lattice step of the box, so at most 41 positions per side: at most 41^2 = 1681 < 4096 vertices are ever discovered. So the cap cannot be reached, and every pocket decision is exact. (The checker also counts cap hits and fails on one.)
