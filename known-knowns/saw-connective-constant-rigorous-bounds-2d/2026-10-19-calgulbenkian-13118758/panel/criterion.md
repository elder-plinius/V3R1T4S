## 4. Question 3: does the Grimmett-Li theorem apply?

I fetched the paper myself: https://www.statslab.cam.ac.uk/~grg1000/papers/loc-6.pdf, 2026-10-19T15:51:57Z, HTTP 200, sha256 2ec73172d21c51a7a520760009d8e28cf44bc3fbaaea5c8c28a2f1ed70cc46fb (identical to the claimant's hash), one attempt, logged in my own fetch log, which is not shipped. Read text:

- Definition 3.1: graph height function (h, H) on an infinite, connected, quasi-transitive, locally finite, simple graph: (a) h: V -> Z with h(1) = 0; (b) H a subgroup of Aut(G) acting quasi-transitively with h H-difference-invariant, h(alpha v) - h(alpha u) = h(v) - h(u); (c) every v has neighbours u, w with h(u) < h(v) < h(w). Unimodular means |Stab_u v| = |Stab_v u| for v in V, u in Hv (3.1); acting freely makes both 1.
- (4.1): bridge if h(pi_0) < h(pi_i) <= h(pi_n), 1 <= i <= n. This is the claim's definition with h = x.
- Proposition 4.2: for a graph with a graph height function (unimodularity not needed), b_n(v)^(1/n) -> beta for every v, with b_n(v) <= beta^(n+r).
- Theorem 4.3: infinite, connected, quasi-transitive, locally finite, simple graph with a unimodular graph height function implies beta = mu.

Hypotheses for h = x - x(o), H = translations by (3a, 3b): graph infinite, connected, simple, degree 3 (checked); h integer valued with h(o) = 0 (origin vertex o); H is a group of automorphisms (translation by 3 in each coordinate preserves types and offsets, so neighbour sets map to neighbour sets), with exactly four orbits (types E, W, N, S), hence quasi-transitive; difference-invariance is immediate since translation shifts x by 3a for both vertices; (c) holds by the offset table; H acts freely (a non-zero translation fixes no point), so every stabiliser is trivial and (3.1) holds, so the action is unimodular. The extra constant r of Proposition 3.2 is part of the paper's conclusion for any graph height function and needs no further hypothesis. The paper's graph being quasi-transitive under H means a free action with four orbits is covered (the Cayley-graph example in the paper, also a free action, makes the same point); the theorem asks only for quasi-transitivity of H and unimodularity of its action, both satisfied. Answer: yes, the application is right, and Proposition 4.2 gives the limit for the start vertex o used, whatever its type. The whole-lattice automorphism group is vertex-transitive here too, but that is not needed.
