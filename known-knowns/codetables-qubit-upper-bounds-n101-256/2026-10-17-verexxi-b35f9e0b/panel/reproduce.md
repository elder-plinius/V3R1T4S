## 2. The definition I implemented (quoted from REPRODUCE.md step 2)
"variables A_0..A_n ≥ 0, the weight distribution of the stabilizer S of an [[n,k,d]] code (|S| = 2^(n-k)); B_j = 2^-(n-k) sum_i K_j(i) A_i is the weight distribution of the normalizer (quaternary MacWilliams identity) and Sh_j = 2^-(n-k) sum_i (-1)^i K_j(i) A_i that of the shadow (Rains); K_j(i) = sum_s (-1)^s 3^(j-s) C(i,s) C(n-i,j-s). Every [[n,k,d]] code satisfies A_0 = 1, sum A_i = 2^(n-k), A_j = B_j for 1 ≤ j ≤ d-1, A_j ≤ B_j for j ≥ d, Sh_j ≥ 0." (In this quote I wrote the ASCII comparison signs as ≤ and ≥, and "j less than d" as "j ≤ d-1", only to keep this report free of angle-bracket characters.)

Rows, with M = 2^(n-k) = 2^127 (the natural integer form; section 3 explains how this was fixed):
- E0: A_0 = 1.  E1: sum_i A_i = M.
- Q_j, 1 ≤ j ≤ 42 (equality): sum_i K_j(i) A_i - M A_j = 0, that is M (B_j - A_j) = 0.
- G_j, 43 ≤ j ≤ 135: sum_i K_j(i) A_i - M A_j ≥ 0.
- H_j, 0 ≤ j ≤ 135 (shadow): sum_i (-1)^i K_j(i) A_i ≥ 0.

Farkas rule used: multipliers u of any sign on E0, E1 and Q_j; multipliers v ≥ 0 on G_j and H_j. Form the combination. If every column coefficient c_i (i = 0..135) is ≤ 0 and the combined right-hand side u_E0 + u_E1 M is strictly positive, no A ≥ 0 satisfies the rows. Reason: c.A ≤ 0 because c ≤ 0 and A ≥ 0, but c.A = (u_E0 + u_E1 M) + sum v_G G(A) + sum v_H H(A) ≥ u_E0 + u_E1 M, which is strictly positive (equality rows contribute exactly their right-hand side, inequality rows contribute nonnegative terms).

## 4. Proof steps re-derived (not just checked)
Let S be the stabilizer, an isotropic F_2-subspace of F_2^(2n) of dimension n-k under the symplectic form, N = S-perp (dimension n+k), A_j and B_j the weight counts of S and N, and d the minimum weight of N minus S.
- (a) A_0 = 1 (only the zero vector has weight 0) and sum A_j = |S| = 2^(n-k).
- (b) For a Pauli c of weight i, the sum over all u of weight j of (-1)^(symplectic product of u and c) is K_j(i). At each of the i positions where c is non-identity, u = I gives +1 and the three non-identity choices give +1, -1, -1, so the factor is (1 - y); at each of the n-i positions where c is the identity the factor is (1 + 3y). The coefficient of y^j in (1+3y)^(n-i) (1-y)^i is the stated K_j(i).
- (c) MacWilliams: the indicator of N is |S|^-1 times the sum over c in S of (-1)^(symplectic product of u and c). Summing over u of weight j gives B_j = |S|^-1 sum_i K_j(i) A_i.
- (d) An element of N of weight below d lies in S (definition of d), so A_j = B_j for 1 ≤ j ≤ d-1; and S ⊆ N gives A_j ≤ B_j for every j. This also covers impure codes and any code with distance above 43, since only A_j = B_j for j ≤ 42 is used.
- (e) Shadow: for commuting Paulis p and q, wt(pq) ≡ wt(p) + wt(q) mod 2, because the two sides differ exactly at positions where p and q are different non-identity Paulis, that is where they anticommute, and S is isotropic. So c maps to (-1)^wt(c) is a character of S. Hence for every u, the sum over c in S of (-1)^(wt(c) + symplectic product of u and c) equals |S| if u is in the shadow set {u : symplectic product of u and c ≡ wt(c) mod 2 for all c in S} and 0 otherwise. Summing over u of weight j and using (b): the number of shadow vectors of weight j equals |S|^-1 sum_i (-1)^i K_j(i) A_i = Sh_j. A count is nonnegative, so Sh_j ≥ 0 for every stabilizer code (Rains' shadow inequality in its elementary form).
- (f) Farkas step: shown in section 2.
- (g) Arithmetic: all 136 column coefficients and the right-hand side were computed in exact Python integers (up to about 2430 bits) by my checker and, separately, by the shipped checker.
Consequence: no [[135,8,d]] stabilizer code with d ≥ 43 exists, so the best possible distance of a [[135,8]] stabilizer code is at most 42.
