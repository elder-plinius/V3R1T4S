# Source-specific macro composition judgment

This is a relative-TCB proof API, not a conjunction of old PASS flags. Every imported leaf is freshly recomputed, source/context-bound, and then consumed by a rule whose semantic conclusion and preconditions are stated below. Retained artifact hashes identify terms; they do not prove a term.

Let S be the mathematical stable finite counter ADT satisfying the actual grammar, modulo tuple/list pair serialization. Extra keys, generators, custom comparisons, mutation and resource exhaustion are excluded. Let C(s) be the full decoded finite-support tape, head0, physical A/front or C/sweep. The machine transition table is parsed from the exact bound machine string. Define T(s,n) as halting after exactly n defined transitions from C(s), H(s) as the actual terminal predicate, and N(s,u) as the actual core returning NEXT with counter output u. A is finite H/N reachability. S is the state sort of the separate lifting logic; it is not the set of arbitrary Python objects.

The target macro judgment is: for every s in S, core(s) terminates with a positive integer defined time tau and displacement delta. A HALT result supplies a complete physical path from C(s) to F0 in tau transitions, including the full returned tape. A NEXT result supplies a complete physical path to a translated C(u), with u in S, and no terminal point before or at that NEXT endpoint. HALT occurs iff H(s). HALT's stored counter phase is metadata; its physical endpoint is F, never A.

The source-specific derivation has these edges:

1. Fresh source-bound helper derivations give decode-validity, canonicality of every reached tape, exact query/mutator meaning and encode's whole-tape translation inverse under bit(p)=0. This imports precise typed helper theorem clauses with matching data/core subjects, not an arbitrary helper success marker.
2. Each source cell has an actual admitted-source execution scheme and an independently derived protected TM word path with the same input/output words, head, phase and time. A generic protected-frame rule extends that path to the arbitrary exterior. It uses exact helper meaning and all proved frame bounds; unknown exterior reads reject.
3. The output physical marker gives scanned bit0. Canonicality plus that fact discharges the actual encode assertion. The codec theorem transports the full tape at head p to the returned relative-head counter. Generated output-language inclusion plus the actual grammar compiler puts every NEXT output back in S. These three premises are separately required; a path alone is not an encoded counter theorem.
4. Exact joint left/right source entry coverage supplies an entry cell for every s in S, with independent integer witnesses for its left and right run lengths. It applies to the source-derived input schemes, including the five actual carry seed cells. Marginal coverage is insufficient.
5. The complete-source carry cut captures actual halt=False and genuinely unbound dt/rule. Every ancestor postlude is checked. At the cut physical state is B, cursor=1+3k and physical time=1+3k; the source phase variable remains front. Exact derivative-language and local-word derivations establish the invariant, body deletion101, strict finite right-word length decrease3, disjoint exhaustive exits and source total times. A generic well-founded prefix-while rule composes these local paths into a finite macro for every finite suffix. It must consume the actual cut/live-state and rank premises; no bounded carry replay supplies this edge.
6. The source-derived complete HALT bitlanguage comes from that finite-while derivation and direct HALT cells. The actual terminal AST is compared to exactly that freshly derived language over every grammar-admitted finite RLE state. Only this predicate equality connects H to the result tag.
7. Total case elimination over the complete entry cover, followed by whole-tape codec transport, yields the macro judgment above. The source's exact final postlude/return ensures there is no unaccounted source effect between the checked exit and actual return.

Three logical premises follow constructively from that judgment:

- terminal_sound: H(s) gives the actual HALT branch and its finite F0 path; choose n=tau.
- next_sound: N(s,u) gives a finite path of length tau to a translation of C(u). Translate a halting path of u back to that endpoint and concatenate; choose total time tau+m.
- halt_decompose: compute the finite macro for s. In the HALT case H(s) holds. In the NEXT case deterministic path-prefix cancellation shows a putative halt at n cannot occur before or at the A0/C0 endpoint, so n>tau. The suffix is a halting path from translated C(u); translate back and choose m=n-tau. Since tau>0, m<n. This produces exactly the existential successor/rank premise used by lifting_logic.py.

The last three arguments use only generic deterministic finite-path uniqueness, prefix cancellation, path concatenation, translation equivariance and natural arithmetic. They do not assume the desired arithmetic iff. The two introductions for finite H/N reachability are definitions. The separate 47-node natural-deduction proof then derives finite TM halting iff finite arithmetic terminal reachability and may be instantiated at the actual empty/front START.

## Trusted primitive rules and boundary

The generic small-checker TCB is explicit: CPython builtin integer/finite-list semantics; correctness of the admitted typed source symbolic interpreter and its cut/definite-assignment correspondence; exact polynomial/rational arithmetic; generic finite-list/word induction; primitive word-path staging; finite automata/threshold/run-power/compiler soundness; the protected-frame/codec interpretation; well-founded finite-prefix while induction; deterministic TM path algebra/translation; and the separate sorted natural-deduction/induction kernel. Source-specific arithmetic, guard partitions, concrete path words, subject identities, endpoint bits, time positivity, source return shape, source case coverage and predicate equality are derived data, not generic axioms.

A remaining OPEN edge must be reported if any of these source-specific inputs lacks a matching fresh derivation or the typed rule preconditions cannot be checked. Calling the result a root theorem merely because all subprocesses succeeded is invalid. No result here supplies novelty/community approval or decides whether the terminal pattern is ever reached.

## Untrusted-certificate API

`python3 code/macro_judgment.py verify RECEIVED_JSON` is the public verification entrypoint. It freshly replays all component checkers and reconstructs the canonical typed proof, then compares every received subject, relation, premise reference, case/output/head/time/phase/frame and logical formula to that derivation. It never admits arbitrary caller-supplied leaf tags. The private leaf-producing constructor and checked component kernels are trusted implementation; they are not an untrusted axiom-import interface. Every rule canonically constructs its conclusion from matching premises. Exported node records are copies, so external mutation cannot modify the internal proof store. The terminal producer consumes the freshly generated carry artifact through CARRY_PROOF_FILE; no frozen input is overwritten.
