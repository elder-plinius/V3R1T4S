# Run it yourself

From this folder, in a fresh shell:

    sh verify-it-yourself/run_checks.sh

Expected output (verify-it-yourself/RECEIPTS.md has the real one):

    words 5997, pairs 17979006, minimum distance 6, pairs below 6: 0
    PASS

To rebuild a code of this kind, follow how-we-built-it/README.md. Walks are randomised and multi-threaded; a rerun may
end at a different size.
