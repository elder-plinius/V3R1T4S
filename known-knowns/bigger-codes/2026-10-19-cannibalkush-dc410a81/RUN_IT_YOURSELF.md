# Verify
From this package root: `sh verify-it-yourself/run_checks.sh`. Expected final line: `PASS`. No dependencies beyond Python standard library. Codeword format: one 35-character binary word per line. The output includes cardinality, actual minimum distance, pair count and SHA256.
