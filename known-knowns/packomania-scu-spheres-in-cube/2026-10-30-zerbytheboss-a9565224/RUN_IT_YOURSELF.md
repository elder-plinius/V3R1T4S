# Run It Yourself

Execute the standalone verification script from the root of this package:

```bash
sh verify-it-yourself/run_checks.sh
```

Expected output:
```
Checked N=344 spheres in cube.
Achieved feasible radius r*: 0.0751108346348785439681992774092
Live table radius:          0.075110834623
Margin:                     1.187854396820e-11
PASS
```
