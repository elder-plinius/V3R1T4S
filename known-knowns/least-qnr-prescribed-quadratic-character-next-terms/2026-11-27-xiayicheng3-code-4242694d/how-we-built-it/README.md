# How we built it (exact commands)

Machine: 4 cores, Linux, gcc 13.3 with OpenMP, Python 3.13 (standard library only).

Lens sieve-first (CRT wheel mod 8*3*5*...*31 = 802241960520, 29,937,600 residues; byte-table filters for 37..47;
q % p for 53..113; base-2 Fermat filter):
```sh
gcc -O3 -march=native -fopenmp -o wheel wheel.c
nice -n 10 timeout 3600 ./wheel 10000000000000000 survivors_1e16.txt   # 95,184 survivors, ~8 min under load
python3 analyze.py survivors_1e16.txt 10000000000000000 b002224.txt .  # needs check_a002224.py and the OEIS b-file
```
Output: sieve-first_analysis_1e16.txt (A002224(30..41) MATCH; n = 42, 43, 44 -> 6072205049848081; CALIBRATION PASS).

Lens independent-recheck (modulus 8*3*5*7*11*13*17*19*23*37 = 33017744760, residues by direct scan, per-residue
incremental loop with filters 29, 31, 41, 43, Euler's criterion computed directly):
```sh
gcc -O3 -march=native -fopenmp -o recheck recheck.c
nice -n 10 timeout 3600 ./recheck 10000000000000000 primes_1e16.txt   # 95,181 primes with the first 30 primes QR
python3 compare.py primes_1e16.txt survivors_1e16.txt b002224.txt .
```
Output: independent-recheck_compare_1e16.txt (identical sets of 95,181 primes and identical QR counts; least for
n = 42..44 is 6072205049848081; none for n = 45 below 1e16).

PREREG.md is the run's frozen pre-registration (null_test: not needed; deterministic exhaustive search). The
survivor files (several MB) are not included; they are regenerated by the commands above.
