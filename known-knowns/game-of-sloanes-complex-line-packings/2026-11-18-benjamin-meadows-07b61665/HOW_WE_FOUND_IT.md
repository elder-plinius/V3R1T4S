# How we found it (contributor text, unverified)

Two unattended numerical search runs on a 4-core machine on 2026-11-01 went over the Game of Sloanes rows with 3 <= d <= 7 that are not marked provably optimal (the first run also took the sporadic rows 4x64, 5x50 and 5x85; the second run added the sporadic row 16x80), using a copy of the leaderboard README as the target list. The runs had no access to the posted packings, so no posted packing was used as a start.

First run (how-we-built-it/src/search.py through driver.py, 2026-11-01): random complex starts; L-BFGS on a log-sum-exp of the squared overlaps with the sharpness p raised in stages from 30 to 3e4; every fourth restart an alternating projection onto the Gram constraints, then descent again; the best three restarts polished by sequential linear programming on the near-maximal overlaps (HiGHS through scipy). This cell had 2 runs in that pass (time budget per run 126 s; extra runs used other random seeds, and the seed of the kept run was not recorded); best coherence 0.7785316667 (how-we-built-it/src/runs-first.jsonl).

Second run (how-we-built-it/src/reopt.py, 2026-11-01, budget 626 s, job in how-we-built-it/src/job_second.json): It started from the first run's packing for this cell and from our first-run packing for (3, 42) with one vector deleted (how-we-built-it/src/prev/out/). Each iteration made a candidate by a basin hop (complex noise of scale 0.005 to 0.4 on an elite packing, then high-p descent), a fresh random start, or a deletion seed, and polished candidates within 2e-3 of the best by sequential linear programming; a long final polish followed. Logged improvements in this cell: 1 by deletion of one vector from the (d, n+1) packing, 1 by basin hop. Final coherence 0.778477832643 (how-we-built-it/src/runs-second.jsonl).

The file is the search's own output, written with 21 significant digits per coordinate. packing-records and pull request 20 hold the same packing converted to float64 and written with 20 decimal places (coordinates differ by at most about 1e-16); there a few small coordinates have only 15 significant digits, below the 16 the criterion asks for, so this package uses the unrounded output. The two files differ in coherence by less than 1e-20.

What failed: rows whose best packings come from equiangular tight frames, SICs or mutually unbiased bases (and rows made by deleting vectors from them) returned to the table value within about 1e-9 and were not improved; about 130 rows of the slice stayed at or above the table. A separate check in the runs recomputed every kept file at 50 digits. On 2026-11-02 the files were released in packing-records (https://github.com/TheBenMeadows/packing-records) and on 2026-11-03 submitted to the leaderboard as pull request https://github.com/gnikylime/GameofSloanes/pull/20.
