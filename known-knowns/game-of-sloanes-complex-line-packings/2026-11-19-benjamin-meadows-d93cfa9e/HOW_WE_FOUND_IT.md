# How we found it (contributor text, unverified)

Six unattended numerical search jobs ran on Kaggle CPU notebook sessions (4 worker processes each), submitted on 2026-11-17 at about 23:07 UTC and running about 11.2 hours each, over 46 Game of Sloanes rows with 3 <= d <= 7 where our earlier packings or the packings in the open pull requests to the leaderboard repository were near the best known value. The code is how-we-built-it/src/gos_kernel.py; each cell was one job of 20070 s on one worker.

Method: the job polishes every packing it is given for the cell and keeps a pool of the six best; then each iteration makes one candidate by a basin hop (complex Gaussian noise of scale 0.002 to 0.4 on a pool member, then L-BFGS on a log-sum-exp of the squared overlaps at sharpness p rising to 3e4), a fresh random start, a delete move (a (d, n+1) packing with one random vector removed, small noise, descent) or an add move (a (d, n-1) packing plus one random unit vector, small noise, descent); candidates within 2e-3 of the best get a sequential linear-programming polish on the near-maximal overlaps (HiGHS through scipy). Every pool member carries a tag naming how its line started (the seed it came from, or `dele`, `add`, `fresh`), and basin hops inherit the tag, so the log shows which start each improvement descends from.

Inputs of the job for this cell (how-we-built-it/src/job_inputs.json, every file by public URL and sha256; how-we-built-it/src/build_job.py fetches them and rebuilds the exact job): same-cell seeds (6, 44): pull request 17, file 6x44_grai.txt (JosiahPark); pull request 15, file 6x44_djma.txt (djma); our packing-records file (Benjamin Meadows); pull request 14, file 6x44_sol.txt (dustinmixon); the leaderboard's posted file 6x44_oai.txt (Dustin G. Mixon (creator code `oai` on the leaderboard)); (6, 45) packings for delete moves: pull request 17, file 6x45_grai.txt (JosiahPark); pull request 15, file 6x45_djma.txt (djma); (6, 43) packings for add moves: pull request 17, file 6x43_grai.txt (JosiahPark); pull request 15, file 6x43_djma.txt (djma). The selection rule: every distinct published packing of the cell (our packing-records file, the leaderboard's posted file, files in open pull requests) as a seed, and the two lowest-coherence (d, n+1) and (d, n-1) packings from the same sources.

Log for this cell (how-we-built-it/src/progress.jsonl): the polished seeds started the job at 0.445894888050 (pr17:6x44_grai.txt). Improvements, in order: basin hops on the `pr17:6x44_grai.txt` line from 20224 s (8 improvements, 0.445891395524 to 0.445811717932); an add move from 21041 s (1 improvement, 0.445588271390 to 0.445588271390); basin hops on the `add` line from 21059 s (14 improvements, 0.445587012837 to 0.445579304748); an add move from 25420 s (1 improvement, 0.445547062989 to 0.445547062989); basin hops on the `add` line from 25439 s (13 improvements, 0.445545584292 to 0.445499842240). Final coherence 0.445499736469 after 3367 iterations (2256 basin hops, 499 fresh starts, 410 delete moves, 202 add moves).

Where the object comes from: The final file carries the tag `add`: its line starts with an add move on the (6, 43) packing of pull request 15 (djma, file 6x43_djma.txt) or its polished copy in pull request 17 (JosiahPark, file 6x43_grai.txt), which holds the same lines in the same order (the job was given both files and draws one at random for each move). Two add moves on that packing gave a new best (0.445588271390 at 21041 s, 0.445547062989 at 25420 s, after the polish); the basin hops that followed on the same line took it to 0.445499736469. The order-preserving comparison in how-we-built-it/src/order_check.txt confirms the descent: the object's first 43 vectors score 6.8e-02 and 6.8e-02 against pr17:6x43_grai.txt and pr15:6x43_djma.txt, against 0.60 to 0.61 for every (6, 44) seed (0 means the same lines, about 0.5 unrelated ones). The object does not descend from any (6, 44) packing.

What failed: of the 46 rows in these jobs, 22 ended below their bar; 16 of those 22 descend from another author's packing for the same cell (a polish) and are not claimed. Most of this job's 2755 basin hops and fresh starts did not improve on the pool.

The file is the job's own output, written with 21 significant digits per coordinate. It has not been published before this claim.
