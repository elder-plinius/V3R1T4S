## Definition used (quoted from CLAIM.md)

> sums over i:
>   SU(3)^2 U(1)_F:  sum (2 F_Q + F_u + F_d) = 0
>   SU(2)^2 U(1)_F:  sum (3 F_Q + F_L) = 0
>   U(1)_Y^2 U(1)_F: sum (F_Q/6 + 4 F_u/3 + F_d/3 + F_L/2 + F_e) = 0
>   grav^2 U(1)_F:   sum (6 F_Q + 3 F_u + 3 F_d + 2 F_L + F_e + F_nu) = 0
>   U(1)_Y U(1)_F^2: sum (F_Q^2 - 2 F_u^2 + F_d^2 - F_L^2 + F_e^2) = 0
>   U(1)_F^3:        sum (6 F_Q^3 + 3 F_u^3 + 3 F_d^3 + 2 F_L^3 + F_e^3 + F_nu^3) = 0
> (SM: drop nu.)
>
> Convention ("inequivalent"): count = 1 + the number of nonzero integer solutions with |F| <= Q_max and gcd 1,
> modulo independent permutations of the three families within each species and the overall sign F -> -F
> (the "1" is the all-zero assignment).
>
> Canonical form of a list line: species order Q u d L e [nu]; each species' three charges sorted ascending; of F
> and -F the lexicographically larger; gcd 1; nonzero; lines in strictly increasing lexicographic order.

## How my own counter works (different from the author's Burnside/Moebius method)

- **Family permutations.** A class under family permutations is one multiset (a sorted triple) per species. There
  are 2300 such triples for Q_max = 11, grouped by their sum.
- **Linear ACCs.** I solved these by hand. With a = sum F_Q and b = sum F_u:
  - sum F_L = -3a, sum F_d = -2a-b, sum F_e = 2a-b, sum F_nu = 4a+b
  - for SM, sum F_nu = 0 forces b = -4a.

  (The hypercharge condition was used multiplied by 6: S_Q + 8S_u + 2S_d + 3S_L + 6S_e = 0.)
- **Quadratic and cubic ACCs.** For each (a,b) I split the species into (Q,u,d) and (L,e,nu). I sorted both halves by
  the key (quadratic sum, cubic sum) and merged them. This enumerates every match exactly.
- **Common factors and sign.** For each matching tuple I computed the gcd exactly. I kept the tuple only if gcd = 1
  (this also excludes zero) and F >= -F lexicographically, which keeps exactly one of each sign pair. Count = 1 + kept.
- **List mode.** It writes the kept tuples sorted, in the canonical line format, so the lists can be compared byte for
  byte.
- **Separate brute-force cross-check.** brute.c runs over all ordered vectors in [-Q,Q]^n using the six raw ACCs, then
  canonicalises each solution and counts distinct classes. This is feasible only at Q_max = 1.
