# Claim

claim: In the convention of the Allanach-Davighi-Melville atlas, the census of inequivalent anomaly-free
family-dependent integer U(1) charge assignments of the Standard Model fermions alone (no right-handed neutrinos)
extends to these rows: |F| <= 41: 66526761; |F| <= 42: 79174540. Each row is certified by a complete canonical
solution list (count - 1 lines; the zero assignment is counted but not listed) identified by the sha256 of its
uncompressed stream in object/counts.txt, and by an independent count (mitm.c).

status: unpanelled (single-context; run 2026-11-11-0917), to be panelled in this run.

target id: anomaly-free-atlas-qmax (charter quarry 5; not a bank entry)

## Criterion (verbatim, from the run's research charter, quarry 5)

"extend the exact census of anomaly-free U(1) charge assignments of the Standard Model fermions (with and without
three right-handed neutrinos) with integer charges bounded by `Q_max`, beyond the largest `Q_max` tabulated by
Allanach, Davighi and Melville; new exact counts, with the full solution list as the certificate."

Shape (charter): "record (exact counts past the published range) with a complete, independently recountable list."

## Definitions used

Charges F_X, X in {Q_i, u_i, d_i, L_i, e_i} (SM) or also nu_i (SMnuR), i = 1, 2, 3, all-left-handed basis
(Q:(3,2)_{1/6}, u^c:(3b,1)_{-2/3}, d^c:(3b,1)_{1/3}, L:(1,2)_{-1/2}, e^c:(1,1)_{1}, nu^c:(1,1)_{0}); sums over i:
  SU(3)^2 U(1)_F:  sum (2 F_Q + F_u + F_d) = 0
  SU(2)^2 U(1)_F:  sum (3 F_Q + F_L) = 0
  U(1)_Y^2 U(1)_F: sum (F_Q/6 + 4 F_u/3 + F_d/3 + F_L/2 + F_e) = 0
  grav^2 U(1)_F:   sum (6 F_Q + 3 F_u + 3 F_d + 2 F_L + F_e + F_nu) = 0
  U(1)_Y U(1)_F^2: sum (F_Q^2 - 2 F_u^2 + F_d^2 - F_L^2 + F_e^2) = 0
  U(1)_F^3:        sum (6 F_Q^3 + 3 F_u^3 + 3 F_d^3 + 2 F_L^3 + F_e^3 + F_nu^3) = 0
(SM: drop nu.) Flipping the sign of a whole species is a bijection of bounded integer solutions, so counts do not
depend on the left- or right-handed basis.

Convention ("inequivalent"): count = 1 + the number of nonzero integer solutions with |F| <= Q_max and gcd 1,
modulo independent permutations of the three families within each species and the overall sign F -> -F (the "1"
is the all-zero assignment). This is the paper's convention: its tables' captions say "Each row contains the all-zero
charge solution", and all 40 published values (arXiv v5 Tables 2 and 3, Q_max 1..10, solutions and symmetric
solutions, SM and SMnuR; the JHEP erratum's Table 1) are reproduced by these counters (status.md).

## Objects

- object/counts.txt: per row the count, list line count, sha256 of the uncompressed canonical list, the lister and
  the independent counter used.
- Lists are regenerated by source/acclist.c and never stored (about 3.3-4 GB each). Canonical line: species order
  Q u d L e; each species sorted ascending; of F and -F the lexicographically larger; gcd 1; nonzero; lines strictly
  increasing (lexicographic, as integer tuples); single spaces, "\n" line ends.
- source/mitm.c counts without listing (meet in the middle over the species, with the convention applied exactly).
- checker/checklist.c checks every line of a stream: 15 integers, |F| <= Q_max, all six ACCs, canonical form, gcd 1,
  nonzero, strictly increasing; prints the number of valid lines and PASS. checker/check_list.py is an independent
  Python version of the same checks (used on samples here).
- source/atlas/: the status record (arXiv record fetches, the owner-supplied v5 text and erratum, table_comparison.txt:
  all 40 published values reproduced in this convention).
