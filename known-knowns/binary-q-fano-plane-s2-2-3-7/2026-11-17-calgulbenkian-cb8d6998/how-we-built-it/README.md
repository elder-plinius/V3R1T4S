# How We Built It

Every element of order `5` in `GL(7, 2)` is conjugate to `pi = G_{5,1} = diag(C(x^4 + x^3 + x^2 + x + 1), I_3)`, which fixes a 3-dimensional subspace `F` (`7` projective points) and partitions the `7,680` planes of `PG(6, 2)` disjoint from `F` into `1,536` orbits of length `5`, of which `1,491` orbits have no internal line intersections. While raw MILP over `1,491` binary variables stalls and uncoupled symmetries `(id_W, g_F)` or `(tau_W, id_F)` in the normalizer `N_{GL(7,2)}(gen(pi)) = GammaL(1, 16) x GL(3, 2)` are infeasible, prescribing a coupled diagonal involution `tau = (tau_W, tau_F)` (`tau_W` acting as Frobenius square `z -> z^4` on `F_{16}` and `tau_F` an involution in `GL(3, 2)`) extends `gen(pi)` to `D_{10}` and collapses the search to `339` non-clashing `D_{10}`-orbits, where exact integer linear programming immediately finds `48` `pi`-orbits (`240` planes) covering `1,680` lines once and every point outside `F` `14` times.
